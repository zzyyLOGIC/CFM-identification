# Identification 网页演示

本地审查版默认先起草完整识别答案，再从原题和附件核验。页面展示目标、总体公式或停止原因、科学条件、估计交接和原答。有明确材料缺口时，页面列出问题，可以在同一次运行内补充并重新核验。直接上传的关系表通过本地文件引用参与支持计算。全部计算和交接仍属于待审核的研究结果。

## 启动

下载完整仓库，在仓库根目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[documents]"
.venv\Scripts\python demo/serve.py
```

Linux/macOS 将 `.venv\Scripts\python` 换成 `.venv/bin/python`。标准入口默认打开 `http://127.0.0.1:8772/`，可指定 `--port` 和 `--no-browser`。根目录的 `python serve.py` 默认监听 8796，由用户打开浏览器。两个入口都支持 `--data-dir` 并使用同一收件器。

在页面“模型连接”中先选择厂商／服务平台，再选择模型并配置该平台的 Key；支持从本地 TXT 导入。密钥仅存在服务进程内存，关闭服务即清除，不写进源码或结果。启动网页、查看示例和历史结果不调用模型；点击开始读取才发起请求。默认每个服务进程最多 1000 次模型请求，可用 `--max-api-calls 50` 显式降低。SUFE 是学校中转服务，与厂商官方接口分开列出；模型 ID 可自填，实际权限由账号决定。接入协议不代表每个平台都已通过真实业务验收。

## 使用与结果

上传用途、对象／关系模板及维护位置见[文件输入说明](../docs/FILE_INPUT_ZH.md)。

- 自由输入业务，或从右侧载入示例并修改。可以附 TXT、MD、JSON、PDF、DOCX、CSV、TSV、XLSX 资料。普通表格默认提取字段和行数；选择“字段说明表”会保留说明行。扫描 PDF 暂无 OCR，空文件、未读取内容或截断会在模型请求前提示处理。
- 对象名单与关系表分别上传，可下载 CSV 模板。完整名单保留孤立对象；须说明关系含义、时期与完整性，不会自动假定未列出的对象对没有关系。当前支持固定、简单、无向、无权的单位网络，不把它当作变量 DAG。
- “导入 CSV／Excel 数据”按用户选择的编号、处理、结果和数值特征列，在本地按名单对齐。须配套对象表与关系表；单时期、二元处理，每个对象保留一行，未回访结果可留空。默认直答与本地核验共享所选择的完整名册、关系及逐行数据。确认发送前可核对材料清单。总体条件均值或分布仍需独立来源。个人页不生成估计或 Policy 输出。
- “检查文件读取”不需 Key、不调用模型；开始分析时重新校验文件。已有普通材料和示例入口仍可使用，不要求所有问题都上传数值表。
- 后台读取目标、事实并复核来源；DAG 路线同样在后台核对因果图、变量、引用和目标范围。遇到输出截断或定位到的读取错误时，仅在次数限制内自动重读；仍未解决时明确停止。只有需要澄清原意或确认必要科学条件时才询问用户。审核边界与数学证书要求不变，模型复核不是科学真实性证明。
- 结果页展示公式与符号、适用条件和证书。没有代入总体数值的 POINT 不是已算出业务效果；有限模型 PARTIAL 的 sharp 性只相对于明确审核的模型成立。
- 使用页不常驻展示覆盖分类和方法清单；输入区保留必要说明，结果围绕当前问题展示。符号含义、证明来源和技术记录可展开查看。只有本题因规模超限停止时，才提示对应上限；文件导入限制仍在上传位置说明。规模指完整研究名单，而非结果记录条数。
- 停止提示区分读取／复核冲突、信息尚未明确、明确不采用假设和当前方法不支持。额外声明保留原文供核对；不会让用户删去真实约束或补造总体数值。无法从已有状态判断原因时，明确说明尚需核对，而不是把它断言为材料缺失。
- 示例保留业务原文和材料，数量由目录自动显示。默认门店题为 100 家门店，可下载 CSV 名册和合作关系表，文字材料按试点、数据和分析前提分组。此页不提供估计数据或估计数值。文献改编边界见 [示例说明](EXAMPLE_SOURCES_ZH.md)。
- “看验收记录”显示原团队网页此前的记录，明确标注为历史结果；修改业务后的新调用不沿用旧结果。程序不会从示例参考答案直接产生新任务的识别结果。

运行记录保存在 `web_runs/runs/`，估计收据和对应包保存在 `web_runs/estimation_inbox/`。页面显示收件状态、点识别查询或部分识别界。估计器的拟合和部署属于下游工程。

## 目录和维护

| 位置 | 职责 |
|---|---|
| `serve.py` | 启动入口 |
| `index.html`、`app.js`、`style.css` | 页面、交互、公式与结果呈现 |
| `input-files.js`、`templates/` | 文件预览、列映射、对象／关系 CSV 模板 |
| `examples.json`、`materials/`、`condition_terms.json`、`condition_explanations.json` | 合成示例、历史结果与统计术语 |
| `backend/` | HTTP、会话、模型请求、后台复核及 ID 调用 |
| `backend/coverage.py` | 汇总已有能力和规模限制，供服务元数据、维护与后续介绍页使用；不决定路由，不批准条件 |
| `tests/` | 正负例、HTTP、隐私、审核边界和页面交互检查 |

`backend/` 调用本仓库的 `cfm_id.project`、读取合同与证书接口；不包含新数学求解器。自动读取／复核沿用原演示，经抽离后不再导入全流程 `autocfm`。测试夹具仅在 `tests/` 中使用，正式服务器不能导入参考答案。日常修改在维护源码的同名 `demo/` 中完成，验收后同步个人发布副本。

共同文件工具位于 `cfm_id_llm/`：`record_files.py` 负责有限记录的映射与覆盖元数据，`network_files.py`／`network_file_binding.py` 负责网络文件与引用，`file_coordinates.py` 负责确定性的编号展开，`upload_receipt.py` 负责读取回执。团队网页复用这些工具，再由自己的适配器生成估计数据；个人页不依赖团队估计模块。

两种网页共用文件合同不表示全部工作流或示例版本相同。个人页保留原九个示例，并从文献题库补充了随机培训政策、缺少邀请规则的追问示例和培训的后门调整题。所有新增方法仍须单独检查目标、条件、来源和证书，不能由文件导入成功推定识别成立。学校追问示例使用自然问法，补充答案在输入区单独折叠。展开答案不会把它带入首次分析；系统追问后，再由用户填写提交。

## 离线检查

```powershell
python -m pip install pytest jsonschema
python -m pytest demo/tests -q
node --test demo/tests/test_review_ui.cjs
```

这些检查不调用模型，不代表新的 LLM 准确率。识别库全量回归仍按根目录 README 运行。
