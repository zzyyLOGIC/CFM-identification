# Student work area

第一次任务的 standalone 学习/验证产物建议放在：

```text
student_work/taskXX/
```

例如：

```text
student_work/task01/
├── setting.md
├── support.py
├── rule.py
├── demo.ipynb
└── test_rule.py
```

这个目录用于 Pull Request review，并不保证最终 merge 到 `main`。
如果某个任务产生了真正可复用的 Identification 抽象，应在 PR 中单独提出并补充共享 tests。
