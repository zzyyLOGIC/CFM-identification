## 数值复核

甲班学1—学4 互为参照组（完全图），乙班学5、学6 互为参照组，班间无参照。规则：受辅导者直接提高 4 分；班平均每提高 1 分、班里每人再提高 0.5 分；无其他途径；班平均按传导全部兑现后的最终口径。均衡解（论文式 (4) 结构，β=0.5）：班平均提高 m = 4S/(n(1−0.5)) = 8S/n，S 为班内受辅导人数、n 为班人数；每人提高 = 4·受辅导 + 0.5·m。

方案 A（学1、学2、学5 受辅导）：

- 甲班 S=2、n=4，m = 8×2/4 = 4；学1 = 4+0.5×4 = 6，学2 = 6，学3 = 0.5×4 = 2，学4 = 2；合计 16；
- 乙班 S=1、n=2，m = 8×1/2 = 4；学5 = 4+2 = 6，学6 = 2；合计 8；
- 全体合计 24，平均 4。

方案 B（学3、学6 受辅导）：

- 甲班 S=1、n=4，m = 8×1/4 = 2；学3 = 4+1 = 5，学1、学2、学4 各 1；合计 8；
- 乙班 S=1、n=2，m = 4；学6 = 6，学5 = 2；合计 8；
- 全体合计 16，平均 8/3。

随机政策与目标：

- Target = 1/2×4 + 1/2×(8/3) = 10/3，即 3.333…；
- 结构检验：每班合计恒等于该班直接效应合计的 2 倍（甲班 a：2×8=16；乙班 a：2×4=8；甲班 b：2×4=8；乙班 b：2×4=8），与班人数无关，这是线性均衡的直接推论；
- 忘掉回馈（只算直接效应）会把目标算成 5/3：直接效应合计方案 a 为 12 分、方案 b 为 8 分，均摊即 2 与 4/3，1/2×2 + 1/2×(4/3) = 5/3，恰为正确答案 10/3 的一半；
- 目标变化版（学3 一人，权重 1）：方案 A 得 2（纯溢出），方案 B 得 5（4 分直接加 1 分溢出）；Target = 1/2×(2+5) = 7/2，即 3.5。方向与全体口径相反：全体 a 优于 b（4 对 8/3），对学3 本人 b 优于 a（5 对 2）。

中间值没有近似替代；8/3 是循环小数 2.666…、10/3 是循环小数 3.333…，写成小数只是展示，不参与后续计算；7/2 为分数精确值。

## 边界

- 不是论文数据复现——论文没有数据；论文未提出本题；
- 借用的是「线性内生效应模型与社会均衡方程、辅导计划的社会乘数机制、参照组构成先验给定」三层结构；
- β=0.5 与直接效应 4 分是自建参数，只受 β≠1 的均衡唯一性约束（p. 534），这一点在来源卡、摘录与参考文件三处写明；
- 按论文 2.3 节的简化只保留内生效应（p. 535），情境与相关效应为零；论文证明加了它们观测上也分不开（Proposition 1, p. 534）；
- 论文的均衡是对总体均值回归说的（式 (3)、(4)，p. 534），本题把同一结构代入两个有限班级，是机制的有限总体化；
- 「删班级划分就不可计算」只在业务层面成立：MIX 路线只有一份邻接与两套名单，识别层核到的是目标形态与政策向量，框架层删边仍能识别；
- 不是真实 LLM 首答准确率；
- 老师复核前不能标正式验收。
