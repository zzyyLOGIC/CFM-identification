# LIT-NET-16 案例设计说明

## 1. 原题

六个团队排成一条协作链试点一套练习计划，原试点每轮只能随机选两个团队启用。季度末整理试点数据后，想知道全部推广时的平均完成情况：

> 如果这 6 个团队都启用练习计划，评价全部这些团队、每个团队权重相同，平均完成率能否由现有总体信息唯一确定？

网络：

```text
团队1 — 团队2
团队2 — 团队3
团队3 — 团队4
团队4 — 团队5
团队5 — 团队6
```

其余团队之间不直接协作。每个团队启用记 1、不启用记 0；结果是考核周内是否完成全部练习，完成记 1、未完成记 0。同伴暴露定义为协作邻居中严格超过一半启用时为 1，否则为 0（平票为 0，孤立点为 0）。

已知（题面声明的精确总体条件均值，不是有限样本估计）：

- 团队1、团队6 在「自身处理=1、同伴暴露=1」时均值都是 1/2；
- 每个团队在每种情形下的均值界限都是 [0,1]；团队1、团队6 的已知均值 1/2 落在该界限内，是对界限的额外收紧。

为什么只有端点有已知均值：试点名额只有 2 个。端点要出现「自己启用、邻居也启用」需要恰好 2 个名额，试点给得出；内部团队出现同一情形需要自己加两个邻居同时启用，共 3 个名额，试点永远给不出。所以内部四个团队在这种情形下没有任何数据，均值只知道介于 0 与 1 之间——他们就是论文里「缺失的那部分人群」。

## 2. 为什么区间是 [1/6, 5/6]

六个对象等权，目标为：

\[
\frac{1}{6}\sum_{i=1}^{6}\mu_i.
\]

已知：

- 团队1、团队6 在全启用情形（自身处理=1、同伴暴露=1）均值 1/2，合计贡献 1/6；
- 团队2–5 在全启用情形的均值只知在 [0,1]，合计贡献 [0, 4/6]；
- 区间两端都可达：四个内部团队的均值可以独立取到 0 与 1（完整有限均值模型、无额外耦合限制保证 sharp）。

所以 sharp 界为：

\[
[1/6,\;5/6],\qquad 宽度\;2/3.
\]

这正是论文第 3 节（p. 1847）识别区域公式的逐字代入：被观测子群均值 µ = 1/2，其权重质量 p = 2/6 = 1/3，缺失子群权重 1−p = 2/3，区域 [µ·p, µ·p + (1−p)] = [1/6, 1/6 + 2/3] = [1/6, 5/6]。原题答案与论文公式同构到每个符号。

## 3. 两个改动版

### 缺条件版

删除「总体信息只有上述精确均值 / 没有额外耦合限制」的完整模型声明。

预期：

- 无法确认模型完整；
- 无法声称 sharp；
- 系统应 `NEEDS_INPUT`。

### 目标变化版：只评试点揭示的两个端点

只评价团队1、团队6，各 1/2：

> 如果这 6 个团队都启用练习计划，只评价试点数据里已知完成均值的团队1和团队6、每个团队权重相同，平均完成率能否由现有总体信息唯一确定？

预期与含义：

- 两个端点在全启用情形的均值都已知（1/2），目标坍缩成点识别 [1/2, 1/2]，宽度 0；
- 这正是论文第 3 节里 µ 与 θ 的对照：被观测子群的均值 µ 点识别（p. 1847「In the point identified case with p = 1 we have」一句的有限版本），加进缺失人群后的总体均值 θ 只能定到 [µ·p, µ·p + (1−p)]。原题答「区域多宽」，变化版答「去掉缺失人群就点识别」，两问合起来就是论文 §3 的全部识别内容。
- 曾考虑只评内部四个团队：答案是 [0, 1]、宽 1，对应论文里 λ 单独完全不可识别，也成立；但宽 2/3 对宽 1 的对比不如「宽 2/3 对宽 0」锋利，且后者直接复现论文的 µ，故选端点。

## 4. 框架语义的一点说明

框架对 bounded 路线有一条相容性规则：目标情形在分配律下概率为正就必须给出该情形的精确均值；只有概率为零的格子才允许落在逐对象界限里产生 PARTIAL。本题的缺失因此是设计性的（名额 2 永远点不亮内部团队的满暴露情形），不是调查无应答式的随机缺失。这与论文「已知倾向得分 p 的随机缺失」在机制上不同、在数学结构上同构：都是「一部分均值有数据、一部分只知有界」。答辩时这一条要主动讲，不要把本题说成随机缺失。
