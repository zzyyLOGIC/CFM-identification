# 网络局部目标：名单、权重与多问题入口

更新：2026-11-26。本页描述默认网页的一个有限入口，不是新的数学方法分类。

## 已接入的内容

同一研究中，可以用自然文字询问一个或多个局部均值、局部比较。各问可以使用不同的处理前评价名单和权重，共用完整网络、抽签设计、结果指标、时期和背景。每问保留方向、名单和自己的证书。评价子群不会裁剪研究网络；不参与平均的对象仍参与原设计和同伴状态计算。

程序从原材料绑定这些信息，调用已有的原生批量局部均值与已验证线性组合实现。数学结果与 LLM 原答分别保存和展示；没有用库结果重写模型原答，也没有把模型原答判为正确的全部依据。

资料复核除逐项结论外，还须从原文分别记录：总体或样本、分布或均值、各对象分别提供或结果联合提供、处理变量范围及实际覆盖对象。程序对照这些记录与读稿，发现不一致时有限重读；不能只靠一个 `MATCH` 通过相互矛盾的复核。这项检查复用现有复核请求，不额外增加一次模型调用；自然语言判断仍可能出错，结构一致不等于原文语义已被数学证明。新请求强制使用此合同，旧审核记录仅按历史合同重放。

同一次来源复核还须区分各对象的中签概率和整份名单的生成规则。“每家一半机会”不能证明各家独立，“这次恰好选中一半”不能证明固定名额。复核记录原文明确的联合规则及引用，再与读取的设计比较；独立抽签另需原句中可定位的明确依据。矛盾先有限重读，材料确实没说时只追问实际抽签方式。该保守文字检查只能阻止一部分误读，不能代替语义复核，也不批准随机化科学前提。共用检查同时用于有 design 字段的有限政策、联合均值及本入口；观察性来源没有随机设计时不要求补独立抽签。旧确定性核验仍保留自己的原文规则，不能用本轮测试宣称其所有措辞均已覆盖。

## 文件与文字合同

评价权重 CSV 使用 `node_id,evaluation_weight`，也接受 `对象编号,评价权重`。可以每问使用一张仅列本问评价对象的表，原文需说明对应哪问；也兼容完整名册表中明确零权重的写法。允许整数、小数和分数；每问权重非负、合计必须精确为1。不自动补零、归一化或改回等权。评价权重不同于抽签概率，也不同于关系边的权重。已引用的权重表另由程序逐行检查数值。

读取兼容仅允许无损移除多余的 `weights.population` 单层包装：外层不能有其他内容，内层键必须与该问已读出的非空名单完全一致，数值必须原样保留为字符串。转换留在本次读取记录中，原始模型答卷保留；随后仍经过同样的字段验证、权重表核对和独立来源审核。缺行、多行、数字变化或有其他内容的包装不自动修复。

原文应说明本次使用该评价权重表，并说明名单和权重是否在处理前确定。缺少这项信息会追问，不从文件名推断。文字名单与非零权重对象冲突、按处理后结果筛人、重复编号或缺行均阻断。

多个问题可以编号，也可以连续自然叙述；模型逐问读取后独立核对是否漏问、方向是否改变、每张表是否对应正确问题。最多16问是入口限制，不是识别定理的条件。一个问题跨多张权重表的拼接暂不支持，不能悄悄取其中一张。缺权重时只追问缺少的内容，补充后重新读取、复核原材料与回答。

每问的本人状态和同伴状态分别对照原文。共同的同伴编码定义不代表每问都限定同一状态，第一问的限定也不自动适用于下一问；只有明确共同适用或明确反向比较时才可共用。新来源审核必须列出逐问的两端分解及依据；候选与分解冲突，即使总体判为“匹配”也会退回有限重读。只明确本人开/不开、未明确同伴状态时保留未定，不能自行补齐事件。原问题已明确按试验后结果选择对象时，直接说明本方法要求处理前固定对象，不再为用不到的同伴字段追问。其他符合条件的问题仍独立核验。

这是来源核对的约束，不能证明模型已理解所有自然语言。历史审核没有这份分解时继续按原合同重放；新实时审核不能省略。分解不替代科学条件确认，也不改变数学公式。

## 数学与审核

本次复用原生随机网络局部目标及线性组合：已知原分配规则、处理前固定的完整网络、完整分配随机化、一致性、所需条件均值有限、每个非零系数状态有正支持，以及对应总体条件均值可用。暴露用于定义问题，不因此自动采用暴露充分性。科学前提需绑定本次原文和目标后明确确认；未决定、不采用、旧确认记录均不能当作通过。

合成研究适配器复用现有 D1–D8 构造器及 E1–E5 的原合同，参数和正支持仍由原库检查；新接口不增加数学能力。独立 Bernoulli、固定名额、分层名额、整组抽签、两阶段、非等概率名额、平衡重随机化的构造兼容经过离线核对。本轮真实网页覆盖独立 Bernoulli＋至少一名邻居，不能据此声称全部设计参数都经过真实模型验收。

真实研究继续受既有外部审核合同限制：本入口目前只开放 D1、严格过半映射及完整批次总体信息，不因新增多问而扩大权限。科学条件同时保留适用对象及完整安排范围；一问满足条件，不代表另一问也满足。同一条件可以按不同对象分别记录采用、不采用和待定；只合并明确采用的覆盖范围，同一对象的冲突不被后写记录覆盖。

已声明但本入口不能核验的单调性、均值顺序、额外限制保留并停止。若目标定义或资料说明被误填为额外假设，先复用既有的有限来源复查；确认误填后完整重读并重新审核，不能按关键词直接删除。声明识别复用既有有限表达规则，并非任意自然语言的完备语义审核。没有支持的科学模型或无法完整绑定的目标，需要专用入口或后续扩展，不能据此判为数学不可识别。

## 多问与下游边界

每问生成原生证据、查询坐标、精确系数并重放。只有所有问题完成才标记整批完成；一问失败不抹去其他问，也不借其他问的证书批准它。更改原文、名单或权重会使旧确认失效。

整组均通过后，交接使用 `ESTIMATE_POINT_BUNDLE`，每问有独立输出、目标指纹、来源绑定、证书指纹和精确系数。相同研究、对象、本人状态及同伴状态的总体均值查询可复用；系数只在同一问内相加或消零，不跨问抵消。交接包重新核对原材料和证书后才写入本地查询队列。页面以本次回执显示问题数和唯一查询数；失败、改题或拒绝前提会撤回旧回执。

这一步登记的是所需总体均值及逐问计算关系，**没有运行样本估计器，也没有接入 Policy**。`joint_query_exchange.evaluate` 可用调用方提供的总体均值逐问代入，返回以问题ID为键的结果，不能当作从样本拟合的估计。任意 CATE/ATT 条件人群、观察性网络、优化目标、跨研究批次和任意 D/E 组合没有因此全部接通。

材料已明确只有有限样本且来源审核无争议时，直接说明本入口需要的总体信息尚未提供，不再为此反复询问设计、权重或确认科学前提。该状态表示当前入口的资料合同未满足，不是数学不可识别证明；若资料本身存在矛盾或另有信息尚未核清，仍保留相应问题。

## 维护位置

- `cfm_id_llm/local_bundle_reading.py`、`resources/local_bundle/SKILL.md`：共用事实、逐问目标、逐条科学范围的读取和独立复核。
- `cfm_id_llm/network_source_route.py`、`cfm_id/project.py`：按原文属性选择读取合同；错误范围可有限重读，即使修正前后仍是同一合同。
- `cfm_id/local_bundle_entry.py`：来源表对照、条件确认、逐问原生调用与证书重放。
- `cfm_id/local_bundle_exchange.py`、`cfm_id/joint_query_exchange.py`：逐问查询、系数、来源和证书交接；旧查询修订规则保持不变。
- `cfm_id_llm/design_scope_audit.py`：边际概率、联合抽签规则与原文依据的共用来源复核。
- `cfm_id_llm/local_target_event_audit.py`：逐问本人状态与同伴状态的来源分解和矛盾检查。
- `cfm_id/network_target_scope.py`、`cfm_id/network_local_targets.py`：原确定性绑定和历史入口仍保留；新来源合同不沿用旧投影中的推断目标。
- `cfm_id/joint_natural_entry.py`：复用共同来源审核、缺项复核、确认记录和证书重放流程。
- `demo/backend/engine.py`、`demo/app.js`：必要追问、共同条件确认、逐问结果。

不得按示例名称或模型是否答对选择数学结果。新类型需要独立的目标、来源、条件及证书验收；不是往关键词表添加一个词就算覆盖。
