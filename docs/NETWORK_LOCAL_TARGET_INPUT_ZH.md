# 网络局部目标：名单、权重与多问题入口

更新：2026-11-24。本页描述默认网页的一个有限入口，不是新的数学方法分类。

## 已接入的内容

同一份研究说明、完整对象名册和关系文件下，可以逐问核验处理前确定的评价名单、明确的评价权重，以及连续编号的多个局部比较。每问保留方向、名单、时期、结果与自己的证书。评价子群不会裁剪研究网络；零权重对象仍参与原设计和同伴状态计算。

程序从原材料绑定这些信息，调用已有的原生批量局部均值与已验证线性组合实现。数学结果与 LLM 原答分别保存和展示；没有用库结果重写模型原答，也没有把模型原答判为正确的全部依据。

## 文件与文字合同

评价权重 CSV 使用 `node_id,evaluation_weight`，也接受 `对象编号,评价权重`。逐行列出完整研究名册；不参与平均的对象明确填 `0`。允许整数、小数和分数；权重非负、合计必须精确为1。不自动补零、归一化或改回等权。评价权重不同于抽签概率，也不同于关系边的权重。

原文应说明本次使用该评价权重表，并说明名单和权重是否在处理前确定。缺少这项信息会追问，不从文件名推断。文字名单与非零权重对象冲突、按处理后结果筛人、重复编号或缺行均阻断。

多个问题用连续的 `1.`、`2.` 或 `1、`、`2、` 编号，一问一行；共同说明放在编号前。最多16问是入口限制，不是识别定理的条件。未归属的段落、漏号或疑似未编号的问题不会静默丢弃。各问可有不同的明确名单；本版只有一张共同评价权重表，不支持多表自动分派。

## 数学与审核

本次复用原生随机网络局部目标及线性组合：已知原分配规则、处理前固定的完整网络、完整分配随机化、一致性、所需条件均值有限、每个非零系数状态有正支持，以及对应总体条件均值可用。暴露用于定义问题，不因此自动采用暴露充分性。科学前提需绑定本次原文和目标后明确确认；未决定、不采用、旧确认记录均不能当作通过。

适配器已连接独立 Bernoulli、固定名额和现有两组固定名额构造，及既有严格过半、邻居人数、至少一名邻居三种局部映射。新真实网页验收覆盖独立 Bernoulli＋至少一名邻居；其他分支不能据此声称都经过新真实模型验收。

已声明但本入口不能核验的单调性、均值顺序、额外限制保留并停止。声明识别复用既有有限表达规则，并非任意自然语言的完备语义审核。没有支持的科学模型或无法完整绑定的目标，需要专用入口或后续扩展，不能据此判为数学不可识别。

## 多问与下游边界

每问生成原生证据、查询坐标、精确系数并重放。只有所有问题完成才标记整批完成；一问失败不抹去其他问，也不借其他问的证书批准它。更改原文、名单或权重会使旧确认失效。

此入口交付识别公式和证书，**尚不自动下发估计**。查询元数据可检查，但不冒充估计端已兼容或已收件。任意 CATE/ATT 条件人群、观察性网络、优化目标、跨研究批次和任意 D/E 组合没有因此全部接通。

## 维护位置

- `cfm_id/network_target_scope.py`：完整名单、权重表、编号问题的无损绑定。
- `cfm_id/network_local_targets.py`：条件确认、逐问原生数学调用、证据与停止状态。
- `cfm_id/direct_verification.py`：报告版本25；不属于此入口的题保持版本24路径及其原有行为。
- `demo/backend/engine.py`、`demo/app.js`：必要追问、共同条件确认、逐问结果。

不得按示例名称或模型是否答对选择数学结果。新类型需要独立的目标、来源、条件及证书验收；不是往关键词表添加一个词就算覆盖。
