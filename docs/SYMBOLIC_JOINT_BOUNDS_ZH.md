# 带参数的有限均值联合界限

本路线是原数值联合求界旁的新增实现，不替换原求解器。它回答：材料保留了未知总体参数时，目标的上下界怎样随这些参数变化。

## 可接收的模型

设有限个总体均值组成向量 `m`，原文明确给出全部限制。

\[
 A m\le b_0+Bp,\qquad \theta=c^\top m+d_0+d^\top p.
\]

`A`、`c` 是固定有理系数；等式展开为两条相反的不等式。每个均值有明确的有限上下限，上下限可以是参数的仿射式；每个参数有声明的有限范围。二元结果还保留 `[0,1]`。参数可以关联多个均值和多条约束，不能逐项单独求界后忽略关联。

当前最多 12 个均值、8 个参数、128 条显式约束；考虑上下限和等式展开后的候选基超过 100,000 时明确返回资源停止，不交付不完整公式。它不支持参数出现在 `A` 或 `c` 中、不支持非线性或个体层限制，也不把有限样本升级为已知总体信息。

## 公式与证书的来源

1. 枚举每个满秩活动约束基 `I`，用精确有理数计算 `m_I(p)=A_I^{-1}(b_{0I}+B_Ip)`。
2. 把该式代回**全部**原限制，得到这一基可行的参数区域。常数矛盾也保留。
3. 检查上界或下界的对偶乘子符号和线性恒等式；只有对偶可行的基进入相应端点表。
4. 独立验证器重新构造原约束，另写矩阵求逆，完整枚举应有的基，核对区域、达到端点的均值、对偶、目标、参数域和来源摘要。它不调用公式生成器。

有限有界可行多面体上的线性目标能在顶点达到最优值；最优点的法锥给出相应对偶表示。因此，每个可行参数值至少属于一个下界基和一个上界基。证书遍历的完备性与原始/对偶可行性共同说明端点准确且可达到。退化基、重叠区域不靠数值采样处理：重叠区域的最优值须相同。没有活动可行区域时，该参数取值下的全部条件不相容。

网页将重复的仿射式合并展示为下界的 `max` 和上界的 `min`，另列参数相容区域。这只是证书的显示方式，不由浏览器重新求解。范围外不作断言，`L≤U` 本身也不能代替相容区域检查。

基础是线性规划的对偶与最优性理论，见 Boyd 与 Vandenberghe 的 [Convex Optimization，作者公开版本](https://web.stanford.edu/~boyd/cvxbook/)；多参数线性规划的分段仿射思想可参见 Bemporad、Borrelli 与 Morari 的 [2001 年技术报告](https://old.control.ee.ethz.ch/publications/2001/7.html)。这些资料提供优化理论背景；本项目的自然语言转换、因果模型完整性和软件实现仍须分别审核，不能用文献引用代替这些检查。

## 自然语言与科学确认

默认直答保留模型原答；另从原材料读取参数、坐标、目标及每条限制，再进行来源审核。模型推导的答案不能成为约束。未决定、明确不采用、未表达的额外限制各自保留。完整模型未声明时追问；真实非线性限制不能忽略后仍声称 sharp。

用户确认绑定本次原文、读取、审核和问题摘要；更改任何一项须重新确认。`SYNTHETIC_TEST` 与 `EXTERNAL_RESEARCH_REVIEW` 分别记录，数学证书不证明科学前提在现实中成立。

### 已采用但当前方法不支持的条件

自然语言读取使用 `symbolic-source-reading/2`。额外条件逐项保留内容、采用状态及原文证据；整体来源复核和逐项复核查看同一份完整声明。数学接口仍使用原 `symbolic-mean-joint-1`，公式、适用条件和验证器不变。旧读取记录按原绑定重放，新模型请求必须返回 v2。

- **明确采用，且独立复核确认属于尚未表达的额外限制**：直接说明该限制和当前方法边界，不再询问是否采用。数学库不计算、没有证书或估计交接；这不是不可识别证明，也不能把模型原答冒充核验结果。
- **明确不采用**：声明仍保留在来源记录中，不进入已采用的数学限制；不能因此报“漏读”。
- **尚未决定、未说明或采用态度相互矛盾**：保留具体追问；回答后重新读取和独立复核，不将回答自动当作通过。
- **候选误读或遗漏**：继续走有次数限制的后台重读，不能改成用户缺条件，也不能用“不支持”掩盖读取错误。

当某项已独立核对的限制足以说明当前方法不支持时，无须再追问不影响这一停止结论的模型完整性问题。其他未解决项及原审核仍保留在记录中，不会被改成 MATCH。该停止诊断不能生成科学批准，正常执行仍需所有来源审核及原有科学确认。

采用状态与不支持诊断的公开验收摘要见[发布验收记录](RELEASE_ACCEPTANCE_ZH.md)。逐次模型原答和浏览器记录仅保存在维护者本地，不随源码发布。

## 估计交接

交接的是参数查询、完整问题和符号证书。接收方须重新核验来源与数学绑定；参数值到达后才能代入已认证公式。未选择样本估计器时只显示登记回执，不显示虚构的估计值、置信区间或生产准入。

实现：`symbolic_mean_contract.py`、`symbolic_mean_solver.py`、`symbolic_mean_verify.py`、`symbolic_mean_entry.py`；共同消费合同为 `joint_query_exchange.py`。
