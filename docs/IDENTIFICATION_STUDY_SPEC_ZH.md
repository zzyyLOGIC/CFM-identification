内部定义以 [research_spec_catalog.py](../cfm_id/research_spec_catalog.py) 为准，[research_spec_model.py](../cfm_id/research_spec_model.py) 形成有版本的内部研究模型，旧入口适配和执行保真见[兼容验收](RESEARCH_SPEC_COMPATIBILITY_ZH.md)。[查看工具](RESEARCH_SPEC_VIEW_ZH.md)消费同一个模型，不另维护展示分类。文献依据见[复核说明](RESEARCH_SPEC_REASSESSMENT_ZH.md)。

开发时按含义明确的属性键维护，例如 `joint_law`、`stratification`、`reference_set`、`endpoint_function`；不再通过新编一个 D/E/R 号表达所有含义。旧编号保留在已有协议、证书及兼容映射中。D3/D5 共用分层名额字段和概率律定义，E1/E3 共用严格过半标签规则；各自不同的参考对象、层数和边界仍单独保留。

一项识别研究先固定研究者要回答的问题、允许使用的信息和愿意采用的条件，再找能证明结论的方法。数学上，若任意两个满足这些条件、产生相同已知总体信息的模型都给出同一个目标值，目标就在该模型类中点识别。若目标可以变化，可以进一步求其可行集合或界。任意方法返回“本方法不适用”都不足以证明目标可变。

## 一份规格要记录什么

六项共同描述一项研究，不是六级执行步骤，也不是每列各选一个类别后即可任意组合。每项内部按不同属性记录，允许多项声明并存。

| 项目 | 负责记录 | 不由这一项自动决定 |
|---|---|---|
| 目标 | 干预或比较、结果形式、评价人群、汇总权重、时期与背景 | 不从“DTE”等名称猜出比较两端，不决定用哪条定理 |
| 分配机制 D | 分配什么、以谁为抽签单位、完整分配规则、阶段及筛选 | 不从边际概率猜联合分配；不把目标政策当历史设计 |
| 暴露映射 E | 参考哪些对象、如何计算、如何分档及处理边界 | 标签相同不自动表示潜在结果或潜在均值相同 |
| 结构与模型 | 研究对象关系、变量因果关系、模型表示及适用域 | 有接触边不自动生成因果箭头；同时描述多种结构不表示已支持联合求解 |
| 已有信息 | 信息对象、总体或样本层次、精确值或符号、覆盖范围与来源 | 有数据文件不等于知道精确总体分布；列出若干项不等于只知道这些项 |
| 科学假设 | 声明内容、适用范围、采用态度及独立审核决定 | 未知、不采用、否定某个命题，以及没有额外约束，分别保留 |

无网络研究无需硬填暴露图。六项是本项目便于维护的组织方式，不能称为文献公认、穷尽所有问题的六类。Aronow 和 Samii 区分原分配设计、暴露映射和目标量；Sävje 区分用暴露定义问题与用暴露限制干扰结构；图识别问题也区分总体律、因果模型和目标干预分布。这些依据支持职责分离，不直接给出本项目的字段数和编号。[Aronow 与 Samii](https://arxiv.org/abs/1305.6156) · [Sävje](https://arxiv.org/abs/2103.06471) · [Shpitser 与 Pearl](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf)

### 共同定义：只登记一次，各处明确引用

名单及其顺序、变量名称及取值编码、结果单位、时期定义和背景定义放在共同定义中。六项引用这些定义，并说明各自使用的范围。

例如“本次有 100 家店”不能自动决定每个问题都评价 100 家店；“记录了 20 项基线特征”不能自动决定目标要固定这 20 项特征。评价名单属于目标，网络节点属于结构，两者均引用共同登记的对象。源资料覆盖哪些店，则由信息项记录。

每个主张保留原文或文件位置、来源版本及其具体支持的参数。一个文档可以支持多个字段，但不能用笼统的“研究来源”替代逐项依据。尤其不能把仅支持名单的引文复制给时期。

`literature_support/classification_map.json` 另外列出的 `scope` 继续作为跨项范围信息：每个目标、信息对象和假设都可能有不同范围。本次不会为了凑成六项而删除它。

### 1. 目标：将“比较什么”和“如何汇总”分开

| 内部属性 | 内容 |
|---|---|
| 干预及比较 | 单一干预，或有顺序的两端比较；实际处理和随机邀请须区分 |
| 其余安排 | 未指定对象保持什么安排，或按哪个分配律在给定状态下平均；不允许省略后默认补齐 |
| 单端函数 | 每端关注均值、事件概率或分布等；实际执行仍限已实现形式 |
| 比较操作 | 原值或有序两端相减等；与单端函数分开记录。未来其他操作不能仅靠改枚举启用 |
| 评价人群 | 全体、明确子集、条件人群或依从者等；依从者通常不能当作可直接列出的名单 |
| 汇总 | 单位结果如何加权；各端是否共享人群和权重 |
| 时期及背景 | 评价的时期；固定哪些背景条件，或按什么分布平均 |

ATE、CATE、LATE、直接效应、同伴效应和政策差值不放在同一互斥菜单里。这些名称涉及不同属性，应保存原名称，并核对它在本题对应的明确含义。旧 `kind` 字段暂不删除。

### 2. 分配机制 D：基础规则与附加步骤分开

先记录被分配的量、抽签单位、完整名单和概率律，再记录分层、名额、阶段和接受筛选。这些属性可以组合；例如整簇分配也可以分层。下面是现有模板导航，不是互斥设计树。D1–D8 保留为现有实现模板：

| 组织后的设计族 | 现有模板 | 必须保留的差别 |
|---|---|---|
| 独立分配 | D1 | 各单位的概率，允许不相等 |
| 固定名额 | D2、D3、D5、D7 | 全体或分层名额；等概率或不等概率；分层名单、联合概率或权重 |
| 整簇分配 | D4 | 簇成员、簇概率以及同簇共同接受处理 |
| 两阶段分配 | D6 | 先选择名额方案，再按方案分配；不能只保留平均名额 |
| 接受筛选 | D8 | 在基础设计上按预先定义的平衡规则筛选，并保留条件化后的概率律 |

D3 和 D5 可在说明上归为分层固定名额，但现有接口对层数的约束不同。D8 的基础设计和筛选规则分开说明，不等于开放任意基础设计的重随机化。观察性分配单独记录，不硬塞入某个随机设计编号。随机化所针对的变量和范围仍须科学审核。

### 3. 暴露映射 E：参考对象、统计量、分档规则

| 内部属性 | 需要记录的内容 |
|---|---|
| 参考对象 | 全部邻居、预先指定的核心伙伴或按组划分的邻居；方向和名单来源 |
| 统计量 | 接受处理的人数、比例、加权和或比例、按组排列的计数向量 |
| 标签规则 | 保留精确统计量，或按明确阈值分档；区间端点与平票归属 |
| 边界处理 | 无邻居、空核心集合、权重分母为零等情况如何定义 |

例如 E3 是“核心伙伴集合＋严格过半”，E4 是“全部邻居＋精确人数”。E1 的平票归低档、孤立点归零，不能在拆解时丢失。虽然人数在名单已知时能算出某些粗标签，某种标签下的均值充分性仍不能自动转移到另一种标签。

这个分解适用于当前模板，不要求所有未来映射都先算一个标量再分档。一般映射可以直接输出向量、依赖多跳结构或个体属性；描述它仍不等于支持执行它。

### 4. 结构与模型：数学背景在这里明确

| 内部属性 | 内容 |
|---|---|
| 模型表示 | 潜在结果、结构因果模型等；保存现有路线所采用的表示与语义 |
| 对象关系 | 节点是人或门店的关系网，及其方向、是否完整、形成时间 |
| 变量关系 | 节点是处理、结果和协变量的 DAG/ADMG，包含声明的潜在混杂 |
| 数学适用域 | 单期或多期、离散或连续取值、固定或随机网络/潜在结果、条件于何种背景 |

“数学背景”没有消失：对象和变量的定义放在共同定义，模型世界放在结构项，随机化、充分性、有限矩等命题放在假设项。当前方法仅支持其中一些明确子域；能描述一种数学世界不表示库已经能在该世界求解。

模型表示与假设可以相关，但同一声明只保存一份内容和审核决定，其他位置引用它。不要让 LLM 分别在“模型”和“假设”中重复猜写一次。

### 5. 已有信息：内容、精度和覆盖分别记录

| 内部属性 | 内容 |
|---|---|
| 信息对象 | 联合分布、条件均值、边际、总体参数等 |
| 提供层次 | 已知精确总体值、可使用的符号总体算子、有限样本或仅有资料说明 |
| 覆盖 | 对象、变量、时期、背景、完整分配或暴露坐标 |
| 完整性 | 是否明确说明“除此以外没有别的信息”，以及这句话对应哪份清单 |
| 资料产生方式 | 抽样、缺失、选择与测量说明；与处理分配机制分开，所需科学假设另审 |
| 来源 | 文件/表/原句、位置及版本；数据文件格式另作载入信息 |

CSV、边表和邻接矩阵是载入形式。有限记录不会因为上传成 JSON 就变成总体信息。若一个等式来自已知总体数值，记录为信息；若它限制可能的因果模型，记录为假设，并链接其原始依据。不能仅凭它长得像等式决定归属。

### 6. 科学假设：命题、采用态度和批准分开

| 按作用整理 | 示例 |
|---|---|
| 连接观察与干预 | 一致性、随机化、给定背景的交换性 |
| 限制潜在结果或均值关系 | 排除限制、暴露充分性、均值顺序、模型范围内的上下界 |
| 保证表达式有定义 | 所需均值存在、有限矩等 |

每条声明分别记录：命题及肯定/否定、对象和适用范围、原文采用态度、来源、审核决定。不要合为一个“成立”布尔量。

- **不采用单调性**：本次不给模型加上单调性限制；不等于断言单调性不成立。
- **是否采用尚未决定**：保留待定；不能改写成作用范围未知，也不能自动采用。
- **在全开时也相等**：如果原文明确采纳，这是一条有范围的额外限制，不能当作重复文字删除。
- **没有其他限制**：是相对于已列清单和模型范围的完整性声明；空列表不能代替它。

支持条件另按来源处理：已知设计下的事件概率由程序计算；观察性总体中必要的支持条件按具体方法审核。结果页应区分“已采用的假设”和“由程序检查的条件”，不要求用户再确认一遍已经可计算的概率。

## 组合、方法和执行顺序

```text
原文与附件 → 保留来源的定义和六项规格
                         ↓
             语义核对、必要追问、科学审核
                         ↓
          匹配满足前提的方法（可能不止一种）
                         ↓
             数学执行 → 证书重放 → 结果交接
```

这是职责顺序，不规定 LLM 必须调用几次。保留当前“直答＋规范化＋库核验”的读取方式：LLM 可以先提出公式或界，核验时仍须明确该答案对应的研究规格。模型原答不是科学批准，也不是证书。

每个组合分三层检查：**组件能否表达、定理前提是否满足、所用入口是否接通**。将某个设计和某个暴露各自登记，并不能证明它们与任意目标、信息和假设的组合都能执行。

本次内部结构整理和共享登记不改变既有可执行组合。例如有限均值盒已有 D1–D8 × E1–E5 的特定组合，仍受节点上限、均值信息、全安排均值充分性及无额外耦合等合同限制；均值顺序、加权暴露和分组暴露不能因此自动加入这个求界器。完整条件见[有限均值盒数学合同](FINITE_MEAN_BOX_MATH_ZH.md)。

R1a、R1b、R2、R3 留在方法及兼容标识的位置。它们有不同目标和前提，可能在一题中有多项适用；并不构成第七项互斥的研究类别。POINT、PARTIAL 是方法执行后的结论，缺资料、待审核和未覆盖是流程状态，均不放进六项的选择菜单。

## 先写目标，再列可用方法

同一份规格可以匹配多项有不同前提的证明。下面把原有编号对照到读者实际需要辨认的概念。填写研究规格时无需选编号。

| 研究目标与设计 | 方法及其必要信息 | 现有及历史技术标识 |
|---|---|---|
| 随机化网络，原设计内一个局部状态或两个状态的对比 | 在每个状态内按原分配的条件分布平均，再按评价权重汇总。需各目标状态有支持，可以允许同一标签内不同名单的均值不同 | R1a |
| 随机化网络，指定完整名单的政策均值或均值差 | 用目标名单的总体条件均值。每份目标名单在设计中均须有正概率 | R1b |
| 同一政策目标，另外有全域均值充分性 | 用每个正权单位的目标签名条件均值。需标签有支持，并明确采用同一单位在所有同标签名单上的潜在均值相等 | R2 |
| 观察性网络，固定背景的完整政策 | 在固定背景下审完整处理向量的交换性。可用有支持的完整名单，或在条件均值充分性下用有支持的暴露标签 | R3 下的两种政策方法 |
| 观察性网络，局部暴露效应 | 按观察分配律平均的标准化、共同基线分层调整、节点及邻居协变量调整各有专门目标、所需总体律和科学条件 | R3 下的三种效应方法 |

例如三库区独立抽签，一个政策指定“只开杉和麻”。完整名单若有支持，直接按该名单的条件均值求解。如果研究者还采纳同标签的均值充分性，同一题可以再用各库区的标签条件均值证明。换成恰抽两个、目标全开时，完整名单概率为零，标签法仍可能有支持。研究者若拒绝外推，就要检验能否构造两个对观测材料给出相同结果、对全开给出不同结果的模型。

这些编号目前仍用于方法分派、合同、证书和工作表，不能只把它们当作历史注释删除。签认绑定包括方法标识、来源和规格，直接改写其中的编号会使原签认失效。面向研究者的名称由展示层提供，证书展开后可查原始技术标识。若将来更换机器键，应采用有版本的新写入格式、旧格式读入和两代重放测试。现有文献支持各自的目标、设计及识别条件，未给出这套编号构成的通用分类。[干扰下的分配策略与效应](https://pmc.ncbi.nlm.nih.gov/articles/PMC2600548/) · [暴露定义与假设](https://arxiv.org/abs/2103.06471)

DAG/ADMG 描述变量之间的因果结构。工具变量是一项研究结构及一组因果限制，可用变量图表达其中部分前提；排除限制和随机性的图示仍不能推出个体处理单调性。后门、前门、一般 ID、Wald 比率和二元 IV 锐界是各有适用域的方法。同一研究可有随机邀请、变量图和网络干扰；组合执行需要相应定理。“没有后门调整集”、一般 ID 给出 hedge、数据与模型不相容、额外假设未获批准，这四个结论各自有不同的含义。[一般 ID 与 hedge](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf) · [Angrist、Imbens 与 Rubin](https://users.nber.org/~rdehejia/%21%40%24AEM/Topic%2004%20IV/readings/angrist_imbens_rubin_JASA_1996.pdf) · [Balke 与 Pearl](https://ftp.cs.ucla.edu/pub/stat_ser/r199-jasa.pdf)

## 日常开发入口及其输出

独立 ID 网页可选“一次读取与多方法匹配”。程序用同一份带引文的研究规格匹配原设计局部对比、完整名单政策均值、暴露标签政策均值、经典后门、一般图 ID、二元 IV 的 LATE 或 ATE。一次模型读取可有一次针对争议字段的复核。决定是否采纳研究前提仍由审核人逐项作出。每个方法分别检查信息和批准，均值充分性待审时仍可使用有完整名单支持的证明。完整分阶段入口覆盖其他已接研究家族，包括观察性网络效应、更多设计和有限模型求界。新入口目前不接动态方案、DiD、RD 或任意自然语言证明。

点公式或界记录研究目标、源总体、变量角色、干预或比较取值、所用公式、数值或精确端点、该方法采用的条件，以及估计该公式所需的总体算子、支持、分层、权重和数据。网络交接带单位顺序、设计、暴露和目标名单或局部臂；IV 交接带工具、实际处理、结果和八格顺序；图交接带总体联合律、边和干预坐标。交接的数学权限为估点、估界或停止。个人版交付这一信息，不执行估计。保留规格、审核票据与结果后可离线重建和核验交接；IV 通过独立枚举潜在类型来验算证明。来源文本的含义仍需要研究者确认。

程序入口为 `cfm_id.project.read_compact(case, call)`。调用者提供 `call(request, stage)` 来返回模型的 JSON 对象。规格进入待审状态时，以 `cfm_id.project.confirm_compact(prepared, review, authority=...)` 提交独立决定。保存了规格、票据和交付后，可用 `cfm_id.compact_entry.replay_delivery` 核对结果及估计合同。网页调用同一组入口。完整方法登记、不同研究权限及已接子域见[当前能力](CURRENT_SCOPE_ZH.md)。
