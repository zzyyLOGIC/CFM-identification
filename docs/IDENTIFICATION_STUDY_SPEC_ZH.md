# 识别规格、方法与估计交接

一项识别研究先固定研究者要回答的问题、允许使用的信息和愿意采用的条件，再找能证明结论的方法。数学上，若任意两个满足这些条件、产生相同已知总体信息的模型都给出同一个目标值，目标就在该模型类中点识别。若目标可以变化，可以进一步求其可行集合或界。任意方法返回“本方法不适用”都不足以证明目标可变。

## 一份规格要记录什么

| 维度 | 必须能回答的问题 | 示例 |
|---|---|---|
| 目标量 | 谁、什么干预和比较方向、什么结果及时间、怎样加权与汇总？ | 保持原抽签的本人开减关；一份完整政策的平均结果；总体 ATE；依从者 LATE；干预风险 |
| 原分配机制 | 哪个量被分配、谁参与分配、用什么规则或概率律、什么是观测到的实际处理？ | 独立抽签、固定名额、整簇随机、观察性自选、随机邀请但实际接受自选。目标政策另记 |
| 暴露映射（有干扰时） | 如何从完整名单和处理前关系得到每个单位的标签？权重、邻居方向、阈值、平票和孤立点如何处理？ | 同伴中过半数开通。标签相同的两个名单仍可产生不同的潜在均值 |
| 可用总体信息 | 哪个总体的哪些联合律、条件均值、边际、约束或符号算子可用？提供的是精确数值、总体声明还是有限样本？来源和覆盖坐标是什么？ | 已知总体联合律足以写出后门函数；少一列基线变量的便利样本未必能估它 |
| 科学假设 | 哪些声明将实际观察连接到目标干预？适用范围、来源和审核决定是什么？ | 一致性，给定基线可交换，完整名单随机化，跨名单均值充分性，IV 独立、排除和单调，DiD 平行趋势 |
| 结构、支持和求值 | 变量关系是 DAG/ADMG，单位关系是接触网，还是两者都有？方法所需分母或暴露有正概率吗？眼前资料能实际求值吗？ | 四点抽三点，全开名单概率为零，各点“本人开且同伴过半”的概率仍为 3/4 |

这些是可同时填写的字段。无网络研究无需硬填暴露图。正支持可以由已知设计计算，也可以是须另审的总体条件。一个条件可以由设计文本提供依据，科学采用则另有记录。Aronow 和 Samii 明确区分原分配设计、暴露映射和目标量。Sävje 说明用暴露定义问题、用暴露限制干扰结构有不同的逻辑要求。可用总体律、因果模型和目标干预分布的区分也直接体现在图识别问题的定义中。这里的字段名、数量和编号是本项目的接口设计。[Aronow 与 Samii](https://arxiv.org/abs/1305.6156) · [Sävje](https://arxiv.org/abs/2103.06471) · [Shpitser 与 Pearl](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf)

## 先写目标，再列可用方法

同一份规格可以匹配多项有不同前提的证明。下面把原有编号对照到读者实际需要辨认的概念。填写研究规格时无需选编号。

| 研究目标与设计 | 方法及其必要信息 | 历史记录中的名称 |
|---|---|---|
| 随机化网络，原设计内一个局部状态或两个状态的对比 | 在每个状态内按原分配的条件分布平均，再按评价权重汇总。需各目标状态有支持，可以允许同一标签内不同名单的均值不同 | R1a |
| 随机化网络，指定完整名单的政策均值或均值差 | 用目标名单的总体条件均值。每份目标名单在设计中均须有正概率 | R1b |
| 同一政策目标，另外有全域均值充分性 | 用每个正权单位的目标签名条件均值。需标签有支持，并明确采用同一单位在所有同标签名单上的潜在均值相等 | R2 |
| 观察性网络，固定背景的完整政策 | 在固定背景下审完整处理向量的交换性。可用有支持的完整名单，或在条件均值充分性下用有支持的暴露标签 | R3 下的两种政策方法 |
| 观察性网络，局部暴露效应 | 按观察分配律平均的标准化、共同基线分层调整、节点及邻居协变量调整各有专门目标、所需总体律和科学条件 | R3 下的三种效应方法 |

例如三库区独立抽签，一个政策指定“只开杉和麻”。完整名单若有支持，直接按该名单的条件均值求解。如果研究者还采纳同标签的均值充分性，同一题可以再用各库区的标签条件均值证明。换成恰抽两个、目标全开时，完整名单概率为零，标签法仍可能有支持。研究者若拒绝外推，就要检验能否构造两个对观测材料给出相同结果、对全开给出不同结果的模型。

编号仅供读取旧合同、证书和工作表。签认绑定包括方法标识、来源和规格，直接改写其中的编号会使原签认失效。面向研究者的名称由展示层提供，证书展开后可查原始技术标识。若将来更换机器键，应采用有版本的新写入格式、旧格式读入和两代重放测试。现有文献支持各自的目标、设计及识别条件，未给出这套编号构成的通用分类。[干扰下的分配策略与效应](https://pmc.ncbi.nlm.nih.gov/articles/PMC2600548/) · [暴露定义与假设](https://arxiv.org/abs/2103.06471)

DAG/ADMG 描述变量之间的因果结构。工具变量是一项研究结构及一组因果限制，可用变量图表达其中部分前提；排除限制和随机性的图示仍不能推出个体处理单调性。后门、前门、一般 ID、Wald 比率和二元 IV 锐界是各有适用域的方法。同一研究可有随机邀请、变量图和网络干扰；组合执行需要相应定理。“没有后门调整集”、一般 ID 给出 hedge、数据与模型不相容、额外假设未获批准，这四个结论各自有不同的含义。[一般 ID 与 hedge](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf) · [Angrist、Imbens 与 Rubin](https://users.nber.org/~rdehejia/%21%40%24AEM/Topic%2004%20IV/readings/angrist_imbens_rubin_JASA_1996.pdf) · [Balke 与 Pearl](https://ftp.cs.ucla.edu/pub/stat_ser/r199-jasa.pdf)

## 日常开发入口及其输出

独立 ID 网页可选“一次读取与多方法匹配”。程序用同一份带引文的研究规格匹配原设计局部对比、完整名单政策均值、暴露标签政策均值、经典后门、一般图 ID、二元 IV 的 LATE 或 ATE。一次模型读取可有一次针对争议字段的复核。决定是否采纳研究前提仍由审核人逐项作出。每个方法分别检查信息和批准，均值充分性待审时仍可使用有完整名单支持的证明。完整分阶段入口覆盖其他已接研究家族，包括观察性网络效应、更多设计和有限模型求界。新入口目前不接动态方案、DiD、RD 或任意自然语言证明。

点公式或界记录研究目标、源总体、变量角色、干预或比较取值、所用公式、数值或精确端点、该方法采用的条件，以及估计该公式所需的总体算子、支持、分层、权重和数据。网络交接带单位顺序、设计、暴露和目标名单或局部臂；IV 交接带工具、实际处理、结果和八格顺序；图交接带总体联合律、边和干预坐标。交接的数学权限为估点、估界或停止。个人版交付这一信息，不执行估计。保留规格、审核票据与结果后可离线重建和核验交接；IV 通过独立枚举潜在类型来验算证明。来源文本的含义仍需要研究者确认。

程序入口为 `cfm_id.project.read_compact(case, call)`。调用者提供 `call(request, stage)` 来返回模型的 JSON 对象。规格进入待审状态时，以 `cfm_id.project.confirm_compact(prepared, review, authority=...)` 提交独立决定。保存了规格、票据和交付后，可用 `cfm_id.compact_entry.replay_delivery` 核对结果及估计合同。网页调用同一组入口。完整方法登记、不同研究权限及已接子域见[当前能力](CURRENT_SCOPE_ZH.md)。
