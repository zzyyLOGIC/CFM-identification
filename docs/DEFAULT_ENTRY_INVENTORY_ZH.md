# 数学能力与默认入口：逐项接入清单

各入口对原题、条件范围、证书和查询的对应检查，见 [原问题与证明的对应关系](QUESTION_PROOF_ALIGNMENT_ZH.md)。

本地更新：2026-11-25。此表登记入口，不增加数学分类，也不把一次读题成功当成全部参数组合均已验收。默认页保留模型原答；数学结论来自原方法及其证书。科学条件仍须明确采用并确认。

## 已有方法如何到达

| 已有能力 | 默认首页的路径 | 保留的范围与检查 |
|---|---|---|
| 随机化网络局部均值、局部效应 | 直接网络核验；未取得证书且无冲突时，沿同一材料继续既有业务读取 | 局部多问题、自定义权重仅在已经接入的目标合同内开放；原 task/batch/linear/effects 的任意参数组合仍可用明确规格 |
| 随机化完整政策均值、政策差、有限混合 | `network_existing_entry`；不再误送需要结果界的联合均值入口 | 固定政策不要求填写不存在的未来混合概率；有限混合逐份核验、保留权重，两端差保留方向；完整安排支持由原库计算 |
| 随机化均值签名政策及其差、有限混合 | 同一政策读取器记录实际提供的签名均值格子，交原签名方法 | 充分性必须明确采用；逐对象签名支持、结果覆盖与科学范围全部检查。政策本身无支持不等于目标签名无支持；也不能反过来用签名支持替代必要的充分性 |
| 观察性完整政策、签名政策及有限组合 | `network_existing_entry`，复用原观察性方法 | 固定背景、同一观测总体律、必要交换性及充分性；额外限制不得丢弃 |
| 观察性局部效应：观测律平均、共同分层、逐对象特征调整 | `observational_effect_entry`，复用原扩展读取及六种信息合同 | 保留每种平均方式的不同条件；有限联合律、因子化律、混合律及分层/特征配置不能互相替代 |
| 有限均值盒、同模型政策差和均值顺序 | 原既有业务/研究入口；可表达的文字模型进入 `joint_natural_entry` | D/E 参数继续由各原合同检查；新联合入口没有替代全部旧专用实现。未知或额外条件保留，不能丢限制后声称 sharp |
| 数值联合均值等式、线性不等式、可复用的均值顺序 | 默认文字与 CSV 来源读取，随后调用 `finite_mean_joint` | 有限明确坐标、精确总体均值、完整限制与科学范围；不把样本频率升级为总体 |
| 固定有理系数、仿射参数的符号联合界限 | `symbolic_mean_entry` | 参数域及每项采用状态保留；原简单符号界仍可用。未知系数、非线性及无限维模型未支持 |
| 经典后门、指定调整集、前门 | 既有默认核验及完整业务读取 | 保留原图准则和审核。用户指定调整集时不能悄悄改用一般 ID 的其他公式 |
| 一般图单处理、单结果的总体分布 | 来源读取后由 `dag_single_source_entry` 转成原一般 ID 合同 | 有限离散图、完整观测联合总体律；完整读取声明仍交原库审核，不绕开 `reading_declarations`。保留原公式或已核验的不可识别见证 |
| 一般图集合干预与联合结果、共同样本的符号公式 | `joint_natural_entry` → 原集合 ID；单处理也可进入 | 无条件联合干预分布，处理和结果分别可为一个或多个变量；保留集合、干预值、变量定义及结果时期。共同样本只交符号总体函数，不把样本等同已知总体数值；分开观测的边际样本不能冒充共同记录 |
| 二元工具变量 LATE / ATE 界 | `iv_natural_entry`，普通文字加八格 CSV 可直接读取 | 工具、实际处理、结果分开；八格精确总体条件概率及完整条件逐项核对。LATE 还需非递减单调性和有效第一阶段；原 ATE 界保留其不同条件 |
| 普通随机 ATE、单臂 ATE、二元 Manski 界 | `population_ate_entry` | 保留均值存在、无干扰、信息范围及完整模型检查；Manski 不默认无混杂，不能忽略额外限制 |

以上方法与执行标识的对应见[方法条件目录](METHOD_CONDITIONS_AND_VERIFICATION_ZH.md)。`method_catalog.homepage_entries()` 是只读登记，不参与批准或选择一个更容易成功的目标。4 个专用合同、12 个原生操作不是新增的 16 种识别理论。

## 仍用明确规格的已有能力

这些不是数学库缺方法，但不能称为任意自然语言已全接通：

- 任意 `TaskSpec`、任意多目标/线性组合，以及超出已接自然目标合同的分组、条件子群与评价权重组合。
- 超出当前无条件联合干预分布合同的复杂图目标与任意规格。不能把已接通的处理/结果集合解释为条件干预、动态干预或一般反事实均已支持。
- `r3_pair` 两份明确观察性规格的对照；不能将其自动改写成一个新的政策差。
- `signature_support`、`quota_support`、`requirements` 为诊断；`legacy_bridge`、`legacy_compare` 为旧证书兼容检查。它们有网页数学规格入口，本身不应被宣传为新的业务识别结论。

首页可随原问上传 `causal-id.math-request/1` 规格，保留原问、材料与原生审核。网页不能仅凭模型推荐自动批准这份规格。条件干预、动态干预、一般反事实或任意图 PARTIAL 若没有对应原方法，仍属于数学扩展，不以增加字段替代。

## 识别和估计的边界

新政策入口交付目标一致的条件均值查询；签名政策使用本人/同伴状态查询，不能错误发送完整安排查询。一般图正例登记观测联合分布和已认证函数。IV 当前登记已认证公式/数值/界限，**不生成样本估计查询**。登记被接收不等于估计器已拟合，也不批准真实研究的生产使用。拒绝前提、未通过审核和不可识别见证均不发送可估计目标。

有限政策组合共享的相同均值只登记一次，系数相加；研究、签名、对象、处理状态、条件任一不同都不合并。各来源政策的指纹保留在查询中。revision 3 在revision 2合并基础上删除净系数为零的查询；新交接 `operator_revision=4` 另在一般图目标中保留已审核的具体干预值。旧revision 1/2/3仍按各自查询规则重放。该兼容只涉及查询表示，不豁免来源范围检查。

若材料直接给出本题所问的精确总体概率，页面可单独展示“材料已经给出的数值”。处理值、结果事件、对象、时期、背景和采用状态必须匹配；不同措辞的范围对应须有独立来源审核，不能由关键词替换决定。样本比例、不同人群/时期、未知范围和相互冲突的值不得直接作答。**这是来源核对，不是图与额外等式的联合数学证明，也不发送估计查询。** 一般图加额外等式/不等式的识别仍未普遍支持。

## 原文与执行范围的保护

均值充分性须单独保存引用支持的对象名单和完整安排范围，不能用目标名单代填。只覆盖A的假设不能用于推导B/C/D；仅在试点安排成立也不能升级为所有安排成立。旧签名记录缺少这些字段时需要重新读取原文并审核，不能仅凭旧证书自动交付。完整安排方法不需要的均值充分性若尚未决定，仍可保留该状态后继续。

单/多变量图在分流前统一检查图外已采用等式及其他限制。暂不能联合核验时明确显示原声明，不发布忽略额外信息后得到的不可识别见证。审核选择“不采用”结束当前路线，“暂不确定”保留待确认，两者都回显且都不会发送估计。

图变量的含义及离散编码放在 `graph.variable_definitions`，不混入额外科学限制。声明只有一个可能取值的变量需要专门简化；当前入口明确停止，不忽略该限制后使用一般图见证。
