中心有六个邻居，暴露为1要求至少四个外围邻居使用 AI。

原试点总共只有三个使用名额，所以中心的暴露始终为0，
中心 (1,1) 状态的支持概率为0。

中心已知的 (0,0) 均值为 1/2，
不能据此确定中心 (1,1) 的均值。

### 7. 独立手算上下界

记中心在 (1,1) 状态下的潜在结果均值为 x。

现有条件仅限制：

0 ≤ x ≤ 1。

因此政策目标为：

θ = (x + 6 × 1/2) / 7
  = (x + 3) / 7。

得到：

下界：3/7。
上界：4/7。
区间宽度：1/7。

手算区间与系统输出 [3/7,4/7] 一致。

### 8. sharp 性与可实现性

有效性：

所有相容模型均有 x∈[0,1]，
所以目标必在 [3/7,4/7] 内。

端点可达：

- 取中心目标均值 x=0，目标达到 3/7。
- 取中心目标均值 x=1，目标达到 4/7。

两种构造均保持六个外围目标均值为 1/2，
并保持中心已知的 (0,0) 均值为 1/2。

其他未指定状态可以选择满足界限的均值。

二元潜在结果可以按各网点、各状态的指定均值，
用相应成功概率的伯努利变量构造，
并使整张潜在结果表与试点抽签独立。

对任意 x∈[0,1]，上述构造同样成立，
因此区间内部每个目标值也可实现。

结论：相对于本题声明的完整模型，
[3/7,4/7] 是 sharp 识别区间。
