# 信息与科学条件的交接

更新：2026-11-24。本说明对应本地交接检查；保留默认直答核验、经典读取和专用研究入口。没有修改数学 Core、LLM 输出 Schema、Prompt 或 Skill。

## 三层各自负责什么

| 内容 | 读取层保存 | 审核层检查 | 数学执行层接收 |
|---|---|---|---|
| 可用信息 | 类型、总体或样本属性、来源、覆盖对象及格子；未知保持未知 | 原文是否支持这些内容，是否属于本次研究和背景 | 已审核的选定总体来源及明确覆盖坐标；样本记录不升级为总体信息 |
| 信息完整性 | 原文明示完整、不完整或未知 | 完整性声明绑定哪一份清单；是否还有未表达的信息 | 只有要求的完整性成立才能构造对应总体律；部分概率表不补零、不归一化 |
| 科学命题 | 命题、范围、来源和原文采用态度 | 对本次目标及资料独立审批；检查拒绝、待定和冲突 | 本方法实际需要且已经批准的条件或原生许可 |
| 其他科学声明 | 原文保留，不为适配方法而删去 | 区分本方法不用的声明与无法处理的额外模型限制 | 不能静默制造更强许可；无法处理的额外限制仍阻断 |
| 版本与来源绑定 | 保留原答和本次来源标识 | 审核绑定当前目标、事实、来源和条件 | 改动后的输入重新审核；旧批准不能直接沿用 |

原文中“采用/拟采用”与审核后的 `ACCEPTED` 是两件事。旧布尔合同中的 `false` 也不能统一解读为科学命题已被证明为假：必须先看字段职责。

## 本轮修复

1. **缺资料不再误报为拒绝科学假设。** 单状态均值和有限政策入口复用现有 `assignment_availability_question`。`known_assignment_law=false/null` 保持原值并追问资料。观察性入口的总体范围完整性、同一研究背景声明，以及有限政策的候选清单完整性，也按信息责任处理。
2. **部分清单不冒充完整分布。** 明确不完整或未知的候选/总体概率表留在缺项状态；概率合计不足 1 时不自动归一化。若读取声称完整，合计不为 1 仍是错误，不能执行。已有确定性错误也不由程序修改。
3. **类型与覆盖范围在进入执行前核对。** 单状态入口原先可能忽略附在完整分布记录上的局部均值格子；现在与局部比较共用格子归属、重复、对象、状态及暴露坐标检查。有限政策与固定政策共用完整安排格子检查。`FULL_JOINT_LAW` 不能只写部分结果对象。
4. **科学冲突保持独立。** 两阶段设计的第一阶段排除声明冲突进入读取复核；未决定仍追问，明确不采用仍不能执行。不是通过确认资料就批准科学条件。

## 其余入口核对结论

| 入口 | 核对结论 |
|---|---|
| 固定政策、两政策对比 | 保留各自来源及端点；有界模型的信息清单完整性与额外约束完整性继续分开；有限模型和顺序条件仍独立审核 |
| 随机化局部比较 | 已有的采用态度、固定背景交接、额外限制阻断继续使用；本轮仅复用原有信息坐标检查 |
| 观察性政策 | 固定 W、正质量分配表、结果覆盖及条件均值充分性仍按现有专用合同审核 |
| 观察性效应 | 实际分配平均、共同分层和节点特征三类保持各自总体来源及条件；不互换调整变量、不从暴露定义推出充分性 |
| 单状态、有限政策 | 补齐本轮发现的信息检查和状态分派遗漏；原生单臂及政策组成证明保持不变 |
| 紧凑入口 | 连续结果仍需明确有限均值条件；二元结果的有界性不能移用到连续结果。没有发现正常入口绕过该检查 |
| 默认直答、DAG、IV、上传原生规格 | 保留原有原问/附件绑定和专用审核。网页后台集成及原生规格重放作为相邻路径检查，不据此宣称新的自由文本覆盖 |

观察性效应中，本方法未使用但原文已采用的其他声明仍留在事实记录并参加审核。证明只使用原生许可中列出的条件；没有把这些附加声明冒称为定理已经使用。出现新的、未支持的模型限制仍须单独处理。

## 验收边界与后续

本地 `reviews/information-science-handoff-20261124/` 保存修改前源码、逐例对照、保护文件指纹及回归记录。10 份有效网络输入的完整计划、结果和证书逐项相等；另外 26 份规格覆盖 12 类原生操作和 6 条研究路线，结果与既有记录一致。负例检查不完整表、资料错配、未采用/未知/冲突条件、作用域不足和过期审核均不调用数学执行。

这些是确定性接口与证书验收，没有调用真实 LLM，也没有操作浏览器。网页后台测试不能当作新的人工网页演示或模型正确率。

下一步如果调整读取合同，应只针对有实测证据的重复填写做减负，不让模型再生成一套六栏总表。旧合同无法区分的状态不能靠迁移代码补猜；真正跨研究合并资料、联合多来源或新的科学模型，仍需要其专门合同与验收。
