# 既有网络能力的默认文字入口

本地版本：2026-11-25。此页区分已复用的数学能力和读取、展示合同；真实模型的验收结果另见开发目录 `reviews/network-entry-closeout-20261125/README.md`。没有改原数学 Core，也没有由模型批准科学假设。

最新逐项盘点见[默认入口清单](DEFAULT_ENTRY_INVENTORY_ZH.md)。随机化政策现在按实际资料形式分派：完整安排资料进入原政策方法；本人/同伴状态均值配合明确采用的充分性进入原签名方法；有限均值模型及额外均值关系仍保留完整约束。固定政策不再误问未来选择概率。签名政策及有限混合向查询端交付本人/同伴状态坐标，不伪装成完整安排查询。原数学方法、科学确认与旧来源记录重放均保留。

## 共同流程与恢复

原始文字、附件 → 带来源的读取 → 独立来源复核 → 必要追问／科学条件确认 → 既有数学方法 → 证书重放。模型直答保留供对照；其中的路线提示只选择读取器，不能选择一个更容易成功的目标。

新增入口共用 `joint_natural_entry.prepare`。一次流程最多两轮完整语义读取；候选合同格式、来源审核格式各有一次单独纠正机会。格式纠正仍须重新提交完整答卷并审核，不自动删字段或替换取值。各阶段长度恢复另按下述上限计数。每次请求均计入调用额度，不把错误提示作为证据或批准。

| 发现的情况 | 后台行为 | 用户看到什么 |
|---|---|---|
| 原文已说明，候选漏写／写错 | 保存具体字段及原句，有限重读 | 不要求用户重复补充已经写过的内容 |
| 来源审核漏掉了效应名称／坐标矛盾，或完整配置漏抄 | 保留原生适用检查的具体诊断，交回同一次有限重读 | 不由程序猜测应改名称还是坐标，也不要求用户重写已上传的表 |
| 原文未提供、明确待定 | 追问具体缺项或采用态度 | 简短的问题，不展示整套字段表 |
| 原文对同一内容有不同说法 | 保留双方原句，询问含义 | 只需解释实际冲突 |
| 原文明确只有有限样本，当前合同只接总体算子 | 说明当前接口边界，保留材料 | 不将样本升级为总体，也不反复索要同样资料 |
| 条件均明确采用，但联立后数学上无解 | 保留完整条件交给求解器 | 经核验的冲突结果；不是要求用户删条件 |
| 第二次读取／复核仍不合格 | 保留失败位置和原答，停止 | 说明模型读取尚未通过，不伪装成科学上不可识别 |

来源诊断绑定本次原文、候选和缺项。分类器不能返回字段修正值、代用户采用假设或跳过审核。模型仍可能误判；这里不是自然语言正确性的保证。

观察性入口因“明确不采用必要条件”或“额外限制未接入”停止时，也对照原文核对该停止理由。忠实保留的拒绝或真实限制继续停止；错填、重复或误归类会回到同一轮最多两份候选的完整重读；真正待定才追问。停止理由复核不能批准执行，也不能直接改动候选字段。采用状态的相互核对放在原有 `coverage` 审核内，旧审核记录和已保存证书保持兼容。

默认直答、来源读取和来源复核若明确返回 `finish_reason=length`，每个阶段最多追加一次完整回复请求。重读及格式纠正共享该阶段的恢复次数；全部原文、字段和来源仍须审核，不拼接截断 JSON。拒绝、超时、网络错误及有效的不通过意见不使用这项恢复。长回复再次中断会显示模型输出问题，不提示用户补写科学条件；每次请求均计入 API 额度。

`不采用`、`未声明`和`尚未决定`不能互换。观察性合同中的 `false` 必须有明确拒绝的原文；未声明／待定为 `null`，原文中的待定说明继续保留。另一种条件已采用，不代表其余条件被明确拒绝。读取和来源审核共用这项说明。

网络专用路线提示，或已上传关系文件但提示缺失／为OTHER时，默认页先独立读取原文中的问题形状和实际分配方式，再选择既有读取器。该步骤不接收模型的计算答案，不从观察分布的混合构成项推导未来政策混合，也不从已知概率推导随机试验。随机化局部目标保留原直接核验结果；无法匹配时不转而索要错误入口需要的条件。完整政策差、多问题等不能被改成局部效应。选择的依据同时交来源审核核对。

### 条件对象与采用态度的独立核对

观察性局部入口增加 `observational_condition_evidence`：独立从原文记录科学声明，不展示候选布尔值，也不让模型直接回答MATCH。程序将声明的关系、给定对象和采用状态与候选比较。给定共同分层B和给定各对象局部特征C_i的条件不能互相代替；原文若确实分别采用两项，则同时保留。

明确采用／明确不采用／尚未决定／未声明分别保留。仅说明“不能由定义推出”不是明确拒绝本次采用，也不授予许可；没有其他声明时保留null。待定项可附候选问题，但是否追问仍由实际方法所需条件判断。新增核对只能提出异议或要求完整重读，不能直接修改候选。真实额外限制仍由原完整来源审核和适用检查保留。

新核对收据绑定原文和读取结果，并纳入科学确认绑定；替换或删除该收据会使确认失效。旧保存结果继续沿其原审核合同重放，不伪造补充审核。自然语言核对仍依赖模型，不能把这些检查称为语义正确性的证明。

原生准备结果若只有待核对说明而没有候选方法，入口先核对说明，不创建科学确认表。真实缺项／冲突才问用户；重复记录的未知状态交回后台重读，不由程序直接删除。网络超时和输出失败单独报告，不提示用户增加研究条件。

## 方法与合同

| 默认入口 | 使用的既有实现 | 输入中必须分开的内容 | 目前边界 |
|---|---|---|---|
| 有限政策混合的平均结果 | 每份完整政策分别识别、重放，再交原有限混合构造器 | 历史抽签规则、未来各政策概率、各政策完整名单、评价权重 | 有限个二元完整政策；不能丢掉不受支持的政策；同一研究的两端有限政策均值差可逐端核验后保留有符号系数；连续/无限政策不在该合同内 |
| 观察性固定完整政策 | 既有完整向量交换性政策方法；原文采用均值充分性时保留对应许可 | 每份固定目标政策、实际历史联合分布、结果均值覆盖、固定背景 | 明确有限的实际安排概率表；边际比例不能自动相乘；一份政策不重复要求填写未来政策分布 |
| 按实际观察安排平均的局部效应 | 原有限／因子化／相关混合观察分配律与局部效应实现 | 本人／同伴比较两端、评价对象、固定背景、实际安排下的平均 | 原合同支持范围；不是任意随机干预或跨背景标准化 |
| 按共同处理前分层平均 | 原共同分层调整实现 | 固定背景、要平均掉的层级、总体层级占比、每层资料和条件 | 明确有限层级；不能改为按处理概率加权 |
| 按本人及邻居处理前特征调整 | 原逐对象特征调整实现 | 本人二元特征、全部关系邻居的特征计数、总体配置及条件均值覆盖 | 既有二元特征与有限配置合同；不是任意连续协变量调整 |

后两类及观察规律局部效应复用 `network_extended_reading` 和 `network_extended_dispatch` 的字段、适用检查及原生输入构造；不再另造一套大 JSON。新增 `observational_effect_source` 负责默认页的原文审核，`observational_effect_entry` 绑定实际科学确认。旧 A0 或旧人工审核收据不会被伪造。

网页公式由本次原生结果的目标、项系数和平均方式渲染，原公式另可展开。新增默认入口经原文审核、逐项科学确认及证书重放后，可向共同查询接口交付目标一致的公式或界限。真实研究使用 EXTERNAL_RESEARCH_REVIEW，合成研究使用 SYNTHETIC_TEST；两者均不自动批准生产使用。登记回执与拟合估计器分开显示，DAG或签名政策若没有现成拟合适配器只登记认证对象，不冒充可执行估计。

### 观察性资料的六种已有形式

| 资料形式 | 保留的信息 | 不允许替代的内容 |
|---|---|---|
| 完整使用名单表 | 每份完整二元名单的总体概率、结果均值覆盖 | 不将缺行补零或将剩余概率归一化 |
| 一份因子化使用分布 | 明确的联合独立说明、各对象使用概率、本人／同伴均值格子 | 各对象边际比例本身不能推出独立 |
| 使用分布的有限混合 | 各构成项占比及项内因子化概率、同一背景下的均值格子 | 构成项不自动变成需要调整的协变量 |
| 共同处理前分层 | 层的总体占比、层内使用规律和分层条件均值 | 固定背景与要平均掉的分层不能合并 |
| 逐对象特征调整 | 完整二元特征配置及占比、配置内因子化使用规律、局部特征条件均值 | 不能只保留评价对象而丢掉邻居的特征 |
| 逐对象特征调整＋配置内混合 | 完整特征配置、每个配置内各构成项的占比和使用概率、局部特征条件均值 | 特征配置占比与配置内混合占比不能互换 |

这六种是当前资料合同，不是全部可识别资料的理论分类。例如枚举入口要求完整使用名单表，某题缺少的行可能不影响其局部目标，但当前入口仍可能无法接收；不能据此宣称数学不可识别。只给边际比例且明确没有联合规律时，也不会补独立假设。停止页面保留来源诊断的具体理由，不要求重复回答已经明确的事实。

真实文字、CSV 上传、追问和证书验收见开发目录 `reviews/network-information-web-20261125/README.md`。接口验收与模型首答准确率分别报告。

## PARTIAL 均值顺序的复用

网络联合均值读取可表达“固定另一项时，本人／同伴使用增加，平均结果不下降（或不增加）”。分别保留：对象名单、本人或同伴方向、顺序方向、是否覆盖另一项全部状态、采用态度和原句。

程序在实际可实现的本人／同伴状态上展开相邻线性不等式，与原等式、不等式共同求界。不能把每次结果的个体单调性当作仅有均值顺序；不能将总体平均趋势扩成每个对象的顺序。待定会追问，不采用则保留声明但不收紧界限。

已知均值可精确代入约束常数项，避免固定坐标把独立小块连成大块。坐标、已知值等式、原范围、每行约束及采用状态全部保留，包括常数矛盾。转换收据保存代入前的行；重放另核对代入前后的仿射恒等式。原 LP、端点／对偶／不可行证书及计算限额不变。

**新增固定系数、仿射参数的符号联合界限。** 参数可以进入均值范围、约束右端和目标偏移；保留声明的参数域、分段区域、达到端点的均值和对偶证据。旧符号均值盒与原数值联合求界不变。参数系数、非线性及任意模型不在新合同内，详见 [符号联合界限](SYMBOLIC_JOINT_BOUNDS_ZH.md)。

## 本轮兼容与恢复

逐行均值来源和声明范围可以随旧观察性合同保留，缺省不增加旧记录字段；范围不足仍拒绝。回答追问后，前次已审目标作为上下文交给读取与复核，不作为原文证据或科学批准；明确改变目标必须引用新回答。

独立声明清单与原文审核分歧时，最多进行一次原文再核对，然后仍受相同审核和完整重读上限约束。“不据资料推断某假设”不能直接登记为“本次明确不采用”。诊断检查只要求重新核对否定范围，不替模型填写采用状态。模型仍可能无法恢复，须报告读取失败而非数学不可识别。

来源审核明确指出入口不匹配时，另允许一次目标形状复核。只提供原材料和分歧，不提供目标答案或推荐方法；只有新的来源分类确实改变，才启动另一套完整读取与审核。分类未变则保留失败。此机制不在多个数学方法间试到成功，也不改变原科学条件。

已有科学条件的待定或拒绝声明若重复放进额外限制，独立声明清单会提出覆盖异议，要求完整重读；不会直接删除该字段。真实额外条件仍须表达；若最终无法辨清，继续停止，不能把停止计作正确识别。

政策读取和复核使用同一份 Skill；其中固定政策、有限政策混合都明确支持同一研究内的两端差值。观察性总体均值覆盖随完整分配概率表登记，不再同时要求重复填写另一张相同的名单表。

新观察性来源清单使用 v2，分别核对一致性、处理前固定网络、均值存在、交换性及结果充分性。条件值相同但引用另一项声明仍触发重读；例如不能把“相同本人及同伴状态对应相同潜在结果”当成一致性的证据。来源重合仅用于发现分歧，不证明科学语义正确。旧 v1 收据只按原绑定重放，不补造新增审核；新的模型请求不能用省略版本退回 v1。
