# 联合干预与网络联合均值：自然材料交接

此入口保留模型原答，另用原始业务文字和附件建立研究规格；数学库独立计算，不把模型的公式当作证书。只在本地接入，未发布。

## 实际顺序

1. 模型直答，并提供候选路线提示。提示只选择读取合同，不能批准方法。
2. `joint_reading` 加载对应 Skill，读取目标、资料、条件及各自来源。CSV 由原上传流程转换，行号保留。
3. 独立复核逐项核对字段与原文，包括条件遗漏和目标范围。格式或引用问题最多修复一次，语义误读最多重读一次；失败记录保留，不将模型错误改写成用户必须补充的科学条件。
4. 缺事实或材料歧义才追问；明确不采用必要前提时停止；额外约束无法表达时说明当前不支持。用户补充可解决原先未知项，不能自动覆盖已有明确矛盾。
5. 程序构造明确数学规格。科学前提由当前用户确认，确认绑定原文、读取、复核、目标和完整规格。
6. 调用已有联合干预或有限均值入口，独立重放证书。网页显示模型原答与数学库结果，暂无自动估计交接。

## 三种内容不能混用

| 内容 | 交接位置 | 对数学执行的影响 |
|---|---|---|
| 数据是什么、样本条数和覆盖 | information / sample_size | 检查信息是否足够；样本不变成总体 |
| 仅求公式、合成背景等非科学说明 | material_notes，仍附来源并逐项复核 | 保存并展示于原始记录，不生成假设 |
| 已采用、未采用、待定的科学条件 | conditions / constraints / remaining | 参与适用检查，或停止/追问；不能移到备注中绕过检查 |

每个来源片段使用由程序生成的 `source_id#L行号`；模型可以只返回片段编号，由程序附回原句。它解决逐字抄写及换行格式负担，不代表引用的语义已经正确。引用片段、完整原文、模型原答与复核记录都保存。

## 两条路线的边界

- **联合干预**：一次同时设定多个变量，求无条件的干预分布；有限离散图、完整且严格正的总体联合分布。条件干预、两方案差或均值不会自动改成分布问题。见 [数学合同](DAG_JOINT_INTERVENTION_ZH.md)。
- **网络联合均值**：固定完整政策水平或两政策差，明确固定无向网络、随机设计、均值充分性、总体均值、范围和全部有限线性约束。程序保留全部可实现均值，包括目标系数为零的坐标；额外等式/不等式共同求界。见 [投影与求界边界](FINITE_MEAN_LINEAR_CONSTRAINTS_ZH.md)。

两条路线都不是任意自然语言的正确性保证。模型复核仍可能误判；科学确认和数学证书分别约束不同层次，不能相互冒充。真实模型和无头 Chrome 原题测试的成功与失败分别记录在开发目录 `reviews/joint-natural-20261125/README.md`。
