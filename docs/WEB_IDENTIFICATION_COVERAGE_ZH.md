# 网页上的识别与复算

首页先保存模型对原问和附件的完整答复。网页单列能从原文或上传表重建的数学问题、采用的前提和复算结果。展开“查看模型原答（供对照）”可以阅读原始答复。估计登记以本次审核绑定的实际回执为准。

| 用户的材料或问题 | 网站能完成什么 | 交给估计端的内容 |
|---|---|---|
| 有处理前网络、分配规则和明确两端的局部效应 | 按原名册核对焦点对象、暴露映射和相减方向，逐对象复算两端联合概率。原设计下有正支持且前提获准时可登记 | 每个对象每一端的总体均值查询、系数及支持概率 |
| 有精确总体单元格、逐对象界限及完整模型说明的政策问题 | 已接单政策、同一模型的双政策差和有声明均值顺序的联合界。已有自由文本验收覆盖固定总名额与严格过半或邻居人数，以及两组独立定额与三级比例。逐对象实名权重须非负且合计为一 | 单政策或政策差的锐界及计算依据。若界收缩为一个已知数值，登记该值。新接的有限模型和均值顺序合同沿用合成研究审核范围 |
| 明确给出因果图或二元 IV 条件 | 图入口可读有向边、指定调整集，并保留未决定和额外条件。二元 IV 可读完整数学声明，也可读逐项说明配合八行总体条件概率表。工具与实际处理分别核对 | 条件识别结论和公式。首页这两条自由文本核验路线没有自动下发估计请求 |
| 有批量、多目标、有不同评价权重的组合或观察性网络数学规格 | 通过“添加补充材料”随原问上传规格，结果区点击“按本次原问核对上传的数学规格”。系统绑定原问、所有附件及原规格；研究者核对目标与材料，再完成该方法原有的审核 | 独立显示并保存原生结果和诊断。原生方法的公式或交接建议与估计收件分别显示 |
| 只有文字，首页暂时无法核准相应方法 | 默认网页在无已知冲突、无待答追问且尚无证书时，保留原答，沿用同一份材料自动继续完整读取与审核。明确冲突、必要追问与科学条件确认仍保留。22 个登记的业务方法共用后续入口 | 经原求解器、证书重放和交接投影的路线可登记总体查询或界限；不能保证任意文字均能成功转换 |

## 如何带入数学规格

在“数学库”选择方法并填写问题规格，展开“将规格用于业务首页”，填写与首页相同的原问，保存 JSON，再随原问上传。原问、分配表或规格发生变化时需要重新审核。在结果区打开规格可以查看本次全部材料。规格检查在本机完成。若要只做本地复算，首页有“本地核验网络公式与估计交接（无需模型）”这一选项。

自备文件使用下列结构。示例查询该库登记的假设目录。查询目录属于诊断，不产生识别证书。

```json
{
  "format": "causal-id.math-request/1",
  "question": "请查看本次研究可参照的识别假设目录。",
  "operation": "requirements",
  "problem": {}
}
```

其他方法的 `problem` 字段按网页显示的原生合同填写。一份上传规格只绑定一个原问和一种原生运算。多目标合同可在一个问题中显式列出多个请求。规格中的目标与业务原问是否同义，仍需研究者对照原材料确认。

## 材料的边界

局部效应和固定政策均值使用不同的目标支持。两政策差在共同的约束模型中求极值。均值顺序属于额外的科学前提，提议采用时逐项等待判断。样本频数不能替代精确总体均值。超出当前文字读取范围的限制需要补充或进入完整方法审核。原生合同覆盖的设计与暴露组合比当前受控自由文本的范围更广。

网页先展示本次材料预览，再请求发送许可；完整表格行供读取和后台复核共同使用，切换读取路线不丢失数据行。详情见 [默认入口与材料交接](DEFAULT_READING_CONTINUATION_ZH.md)。
