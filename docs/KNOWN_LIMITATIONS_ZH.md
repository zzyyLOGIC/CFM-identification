# 已知限制与下一阶段

更新于 2026-11-26。当前识别范围与发布检查分别见[能力与入口边界](CURRENT_SCOPE_ZH.md)、[默认入口清单](DEFAULT_ENTRY_INVENTORY_ZH.md)和[收尾记录](RELEASE_ACCEPTANCE_ZH.md)。下面的历史测评按其发生时间解读，不作为当前总体准确率。

| 限制 | 目前做到什么 | 仍需什么 |
|---|---|---|
| 自然语言读取及复核不稳定 | 目标优先 A0、共享定义、来源审核与有界重读已接通 | 单独保留首答和复查成绩；漏读、错分与漏引继续阻断，不追加无界重试 |
| Schema 与语义是两层检查 | 观察性＋未知分配律可合法保留；结果定义一致性规则已贯穿请求、解析和诊断；顺序关系与采用态度的职责已说明 | 格式通过不能代替原文含义正确；未决定不得改成采用，重复备注不能被自动删除 |
| 数学入口与真实模型覆盖不同 | 经典共同读取之外，默认入口已接政策、观察性局部效应、联合干预、数值/符号联合均值及二元 IV 等专用来源路线 | 任意多目标、条件子群和参数组合不能据此宣称全部自然语言接通；新业务仍受原合同限制 |
| 多问题、子群与权重 | 同一随机网络研究的多个局部均值/比较，可分别使用处理前名单和权重；逐问审核、求解和重放，整组通过后登记查询 | 不等于任意 CATE/ATT、按试验后结果筛选、观察性多目标或跨研究组合。真实研究的科学确认权限仍按原合同；[具体输入边界](NETWORK_LOCAL_TARGET_INPUT_ZH.md) |
| 查询交接与实际估计不同 | 相同总体均值查询可共用，各问系数和证书分别绑定；未完成整组或拒绝前提时不交付 | 登记回执不代表已运行样本估计器或 Policy。有限样本不能在读取时升级为精确总体信息 |
| 文件输入有明确范围 | 对象表、关系表、字段说明与CSV/Excel记录已接入，按稳定ID和实际覆盖检查；保留来源和未读取内容 | 固定简单无向无权网络、单时期二元处理；暂无OCR、任意图文件、类别编码、插补与面板合并；[详见输入说明](FILE_INPUT_ZH.md) |
| 非采用、未知与真实约束不同 | 可分别记录均值充分性和个体潜在结果充分性；非采用不等于断言为假，必要条件未知仍追问 | 模型仍可能误填字段；真正额外约束不能删除或套用未覆盖定理 |
| 共同诊断视图并非所有路线同构 | 政策均值、两政策、随机化效应、观察性固定背景政策复用公共诊断；其余保留专门证据 | 后续按证据形状适配，不为统一显示复制求解器或许可 |
| PARTIAL 有限 | 原 D1–D8 × E1–E5 均值盒和专用顺序合同保留；另接有限均值线性等式/不等式的数值求界与固定系数、仿射参数的符号联合界限 | 原盒模型 D1–D6最多12节点、D7/D8最多8节点；新联合路线各有规模限制。未知系数、非线性、个体层限制不自动支持，不能丢掉额外条件后声称 sharp。见[数值合同](FINITE_MEAN_LINEAR_CONSTRAINTS_ZH.md)及[符号合同](SYMBOLIC_JOINT_BOUNDS_ZH.md) |
| 图方法与工具变量 | 后门、指定调整集、前门保留；一般 ID 的集合干预/联合结果和二元 IV 已接默认文字与附件路线 | 条件干预、动态干预、一般反事实和任意图 PARTIAL 未覆盖；图外限制暂不能联合核验时停止。材料直接给出的数值仅作来源核对。IV 不生成样本估计查询 |
| 研究审核不是生产认证 | 审核绑定内容、版本、目标和来源；网络保留合成研究限制 | 真实身份签名、跨副本撤销、多人协作与生产准入尚未完成 |
| 历史协议与物理布局 | 旧导入、hash 来源 DAG 和研究会话兼容保留；当前推荐配置有唯一入口 | 新开发遵循职责地图，不能认定所有数学文件均已归位或完全单向依赖 |
| 证据的外推边界 | 有离线正负例、真实 API、网页和独立重放记录 | 小样本开发复测不是盲评总体准确率；重放不是 Lean/Coq 形式化证明 |

近期 GPT 接口修复后，前门和均值顺序各取得真实成功，未决定负例正确停止；这些是已知问题的开发复测，不能把此前九题比较改写为 9/9。LongCat 也可能因 A0 格式或字段归属失败，不能用安全阻断冒充正确读取。

有限均值盒的真实业务测试还出现：将已经记录的均值界限再次填为额外约束、把簇抽签误写成分组固定名额、漏填节点界限，以及后台复核错误认可或否定这些字段。D7/D8 的字段说明和结构错误定位已补齐，复核请求也带上完整设计枚举，但这不保证模型总能正确填写。新机制的数学参考验收覆盖不等于同范围的自然语言成功率。原答、格式重读、语义重读和最终执行必须分开保留。

历史证据仍见[共同定义读取](SHARED_DEFINITION_ACCEPTANCE_ZH.md)、[均值顺序读取](MEAN_ORDER_READING_CONTRACT_ZH.md)、[R3 签名验收](R3_SIGNATURE_ENTRY_ACCEPTANCE_ZH.md)、[设计／暴露验收](NETWORK_DESIGN_LIVE_ACCEPTANCE_ZH.md)。这些记录描述各自日期、配置和材料，分母不同，不合并计算。

下一阶段优先固定跨模型、未参与调试的完整业务评测，并按错误影响划分：目标／信息／科学条件的关键误读、说明性引用、传输失败和程序异常。只有可复现接口矛盾、审核绕过或数学错误立即修复；模型偶发失败作为限制保留，不为单题不断加长 Prompt。


## 二元 IV 研究接口（2026-11-11）

原结构化研究接口保留。2026-11-18 的本机 ID 网页可依工具、实际处理、目标及条件表匹配二元 IV，不执行估计。不同步骤的审核决定仍需逐项提供。[当前入口](CURRENT_SCOPE_ZH.md)

在此前发布版本中，−10⁻⁹ 的单调模型矛盾曾被判为 LATE 点值，宽度 10⁻²⁰ 的 ATE 区间也曾被判为单点。本机版已分别给出严格不相容证书及 [0, 10⁻²⁰] 的精确原始／对偶证书。历史浮点证书只有在其数字足以通过当前精确核验时才可重放。此修复针对给定总体条件概率；抽样误差、弱工具推断及连续 IV 仍在本合同之外。[求解](../cfm_id/iv_exact_transport.py) · [独立重放](../cfm_id/iv_exact_verify.py)
