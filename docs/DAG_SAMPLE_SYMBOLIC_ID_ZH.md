# 联合干预：样本与符号识别公式

`dag-joint-id-1` 保留已知总体联合分布的旧合同和证书。`dag-joint-id-2` 则保留 `information=FINITE_SAMPLE`，只交付作为目标观测分布函数的识别公式，不把经验频率或样本均值升级为精确总体数值。

这遵循识别与估计的区别：[Shpitser 与 Pearl（2006）的 ID 算法](https://aaai.org/Papers/AAAI/2006/AAAI06-191.pdf)研究能否以观测分布表示联合干预分布。是否知道这个分布的精确数值，与是否存在该表达式是两个问题。以下输入限制是当前实现的范围，不是对论文全部理论范围的宣称。

## 仍须检查

- 原有完整因果图及潜在共同原因、递归结构模型、联合完美干预和严格总体正性条件继续审核。样本中每格都出现不能证明总体正性；这里未降低原有正性门槛。
- 图中变量必须在同一批记录中共同测量，资料与目标的人群、时期、结果定义和背景一致。变量名单不等于共同测量；分开的边际表不能直接拼成联合分布。
- 只覆盖原静态无条件联合干预分布、有限离散变量及原计算规模；缺失变量、选择机制、跨人群推广、条件干预和额外限制没有因新接口而自动获准。
- 科学条件仍由当前来源绑定的确认记录批准；未决定会追问，拒绝会停止。原有数学求解与独立规则核验不变。

## 版本与下游

新字段 `jointly_observed` 来自原文，未知为 null。旧读取没有该字段时不向历史绑定补默认值。v2 数学问题另携带 `joint_observations=true`、`sample_size` 和 `output_kind=SYMBOLIC_FUNCTIONAL_ONLY`；证书独立检查 `numeric_population_known=false`。篡改信息性质，即使重新计算摘要也不能通过重放。

网页、明确规格入口及研究目录共用版本解析。v2 交接保留干预值和样本来源，只登记待估计的总体联合分布及公式，`estimator_executed=false`。采样的代表性、缺失处理及有限样本估计准确性未由该证书证明。不得把 POINT 标签解释成已经得到效果数值。
