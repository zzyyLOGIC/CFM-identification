# 有限均值等式与线性不等式

2026-11-25，本地新增 `FINITE_MEAN_JOINT`。这是独立新增的有限均值求界实现，不改原有盒模型、均值顺序、Manski 或 IV 算法。

## 模型与识别对象

研究者明确给出有限均值向量 μ，以及完整的线性限制模型。每个坐标须有含义、范围、来源；若数值已知，必须是被声明的总体均值。未知总体值可以保留未知，不从样本平均值补齐。

统一表示为 `Aμ ≤ b`，等式拆成两条不等式，目标为 `θ=cᵀμ+d`。所有已采用的限制共同求解：

`L = min θ`，`U = max θ`，约束为同一完整模型中的全部行。

此处复用线性规划的对偶性与 Farkas 不可行性证据；参考 [Waterloo 的线性规划与对偶讲义](https://cs.uwaterloo.ca/~r5olivei/courses/2024-spring-cs466/lecture-notes/lecture11/)。下面的模型解释和软件证书是项目实现，不能把该讲义当成网络因果识别定理。

## 为什么证书能核验

1. 上界证书给出可行均值 `μ⁺`，且 `cᵀμ⁺+d=U`；另给出非负乘子 λ，满足 `λᵀA=cᵀ`、`λᵀb=U−d`。任何可行均值都不超过 U，而证书中的均值达到 U。
2. 下界同理，对目标 `−c` 检查可行端点和非负乘子。
3. 冲突证书给出 λ≥0，使 `λᵀA=0` 且 `λᵀb<0`，因此没有均值能同时满足全部条件。此时输出 `INCOMPATIBLE`，不输出识别区间。

上下界相等返回 POINT，否则返回 PARTIAL。二元结果下，每个合法均值可由相应 Bernoulli 变量实现；实值结果下可用常量实现。它们的有限联合构造满足该模型中全部均值限制。因此端点及其间范围在**这个明确的有限均值模型**内可达。

这不证明任意网络潜在结果模型、个体单调性、联合结果分布、排除限制或其他未编码关系都可由该构造实现。若实际研究还有这些限制，必须先建模；不允许靠“模型已完整”按钮忽略它们。

## 接口和资源边界

| 输入/状态 | 处理 |
|---|---|
| 等式 EQ、≤ LE、≥ GE | 同时保留；已知均值也作为等式保留 |
| ADOPTED | 放入共同可行域 |
| NOT_ADOPTED | 保留原文和状态，不用于缩窄范围 |
| UNDECIDED | 追问/停止，不能按“没有限制”运行 |
| 尚有未表达的限制 | UNSUPPORTED，原限制保留 |
| 仅有限样本、来源不明或模型未列全 | NEEDS_INPUT |
| 计算超过当前精确搜索上限 | RESOURCE_LIMIT，不能解释成不可识别 |

所有系数是有理数字符串。最多 128 个均值、256 条声明约束；按共同约束连接的坐标分块，每块顶点/对偶搜索最多 100,000 次候选系统。上限用于控制演示资源，不是数学理论上限。现阶段不提供符号参数解、非线性约束或通用大规模优化器。

求解器 `finite_mean_joint_solver` 产生候选端点与对偶/Farkas证书；`finite_mean_joint_verify` 独立从原规格重建约束核验，不调用求解器或其约束编译函数。浮点优化器只在离线交叉检查中使用，不作为准入依据。

## 例子

设新、旧方案完成率各在 0 到 1 之间，目标是新减旧：

| 明确采用的限制 | 核验结果 |
|---|---|
| 没有其他限制 | `[-1,1]` |
| 新旧总体完成率相等 | `[0,0]` |
| 新方案至少提高 20 个百分点 | `[1/5,1]` |
| 同时至少提高 3/4、最多提高 1/4 | 条件冲突 |
| “至少提高 20 个百分点”尚未决定 | 停止等待决定 |

网页示例明确标注为合成题。限制属于本题采用的前提，不是程序从数据中发现的事实。

## 接入状态

CLI、数学库网页、随原问上传规格三处共用 `dedicated_entries`。审核绑定目标、全部来源和全部约束；修改后旧审核失效。新入口不自动下发估计请求。

默认“直答加核验”已增加有明确边界的网络材料转换：自然业务文字、实际上传的节点/关系 CSV、总体均值表和研究说明，先经过来源读取与独立复核，再由 `network_joint_projection` 转换成上述规格。采用状态和全部来源一起保存。真实模型与网页记录见开发目录 `reviews/joint-natural-20261125/README.md`。

转换要求固定的完整无向关系网、已知随机设计、相同本人/同伴状态的均值充分性、同一背景和时期的精确总体均值，以及完整声明的有限均值模型。只处理已有八类设计、五类暴露规则内的固定完整政策水平或两政策差，权重须明确。个体单调性、非线性关系、更丰富的总体联合分布不能删掉后再声称等价。

程序枚举所有可实现的“对象 × 本人状态 × 同伴状态”均值，保留目标系数为零但可能受额外关系约束的坐标。已知均值必须对应有支持的单元格；约束的 EQ/LE/GE、方向、系数、范围和采用状态完整交接。投影重放另行枚举完整安排，核对支持、暴露和目标权重；求界之后仍独立核验端点/对偶或冲突证书。

当前投影最多 12 个对象，扩展设计 D7/D8 最多 8 个，且不能超过 128 个均值坐标。软件限额不是理论限制。科学条件未明确采用时追问；明确不采用必要前提时停止，不诱导改为采用。所采用的模型和线性关系仍须当前用户确认；本路线不自动下发估计请求。
