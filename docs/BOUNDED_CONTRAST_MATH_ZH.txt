1. 问题设定
-----------

给定同一网络 G=(V,E) 上的两个政策 p^{(1)} 和 p^{(2)}，共享相同的：
 - 设计分布 q(t)（其中一种 D1-D6）
 - 暴露映射 S（其中一种 E1-E5）
 - 科学边界 L_i, U_i（每个节点 i）
 - 已知 A4 值集合 K = {(i,a,e) -> v}
 - 声明顺序约束（NodeOrder）

目标：识别

  Delta = mu(p^{(1)}) - mu(p^{(2)})
        = sum_{i} w_i * (m_i(c_i^{(1)}) - m_i(c_i^{(2)}))

其中 c_i^{(1)} = (p_i^{(1)}, S_i(p^{(1)})) 和 c_i^{(2)} = (p_i^{(2)}, S_i(p^{(2)}))
是同一均值集合 M 中的不同单元格。


2. 与"分别求界后相减"的区别
----------------------------

核心区别：共享均值集合 M 意味着 p^{(1)} 和 p^{(2)} 的目标单元格属于
同一个约束系统。分别求界后相减会导致：

  [min m(c^{(1)}) - max m(c^{(2)}), max m(c^{(1)}) - min m(c^{(2)})]

这比真实区间更宽，因为：

  1) 共享抵消：如果 c_i^{(1)} = c_i^{(2)}，则该项对 Delta 的贡献确定为 0
  2) 共享未知：如果 c_i^{(1)} != c_i^{(2)}，它们共享同一组 L_i, U_i 和顺序约束
  3) 耦合不确定性：分别求界假设 c^{(1)} 和 c^{(2)} 可以"独立地"达到极端值，
     但实际上它们必须同时被同一个 M 容纳


3. Signed-box 优化方法
----------------------

3.1 系数构建

对每个单元格 c = (i,a,e) ∈ C，构造 signed 系数：

  d(c) = sum_{nodes i} w_i * (1[c = c_i^{(1)}] - 1[c = c_i^{(2)}])

则 Delta = sum_{c ∈ C} d(c) * m(c)。

注意 d(c) 可以取正值、负值或零。

3.2 逻辑界（引用上限）

在不利用 A4 和顺序信息时，仅从 L_i, U_i 可得：

  logical_lower = sum_{c} min(d(c)*L_{c[0]}, d(c)*U_{c[0]})
  logical_upper = sum_{c} max(d(c)*L_{c[0]}, d(c)*U_{c[0]})

这是"不求佳界"的上界——比真实区间更宽。

3.3 收缩界

利用 A4 值和顺序约束，构建各节点的可行多面体 M_i。
对每个节点 i，设其单元格为 (c_1,...,c_k)，系数为 (d_1,...,d_k)。

因为 delta_i = sum d_j * m(c_j) 且 M_i 是紧多面体：

  delta_i_lower = min_{m ∈ M_i} sum d_j * m(c_j)
  delta_i_upper = max_{m ∈ M_i} sum d_j * m(c_j)

总区间 Delta ∈ [sum delta_i_lower, sum delta_i_upper]。

3.4 锚点枚举（求解方法）

对每个节点 i：

  1) 确定锚点集 A_i = {L_i, U_i} ∪ {v: (i,a,e) -> v ∈ K}
  2) 对每个单元格 c_j，其可行值为 A_i 中的子集值
  3) 枚举所有可行组合（满足所有 box/order/A4 约束）
  4) 对每个可行组合计算目标函数值
  5) 取最小/最大

如果 d(c) = 0，则该单元格不贡献任何不确定性——这是 signed-box 的核心优势。


4. sharp 性证明
---------------

对于 signed-box 优化，sharp 性指区间端点由可行均值赋值达到。

证明方法（与 mean_order_solver.py 一致）：

  1) 锚点枚举确保找到所有顶点
  2) 顶点坐标来自 A_i 的有限子集
  3) 对偶乘子：对 upper 端点，构造非负乘子 lambda 使得：
       sum lambda_r * constraint_r(m) = objective(m)  对所有 m ∈ M_i
     且 lambda 只作用在 active 约束上
  4) lambda 的存在性是端点最优性的充要条件


5. 整合同一背景/模型的要求
--------------------------

对比组合须满足：第1和第2政策引用同一 Background 和同一 modeling。
验证方式取自 bounded_contrast_solver.py：

  validate_pair(inquiries, information)

检查点包括：
  - 两个 inquiry 对应相同的网络和节点顺序
  - 共享的信息源（A4 和 bounds）
  - 第1政策的节点顺序与第2政策相同
  - 共享的节点赋值和暴露映射

如果共享属性不一致，返回 CHECK_BLOCKED: ACTUAL_COMPARISON_AND_REVIEWED_TARGETS_DIFFER。


6. 推广到所有 30 种 D×E 的组合
-------------------------------

对每种组合，对比求解与单政策求解共享相同的支持概率、单元格枚举
和约束结构。区别仅在于目标系数的符号。

检查表（参见 30_COMBINATION_CHECKLIST.md）中每种组合的两目标检查
共享相同的单元格枚举和约束构建步骤——只在目标函数上不同。

因此，一旦某种 D×E 组合的单政策均值求解器通过了测试，
其对比求解器自动获得相同的支持概率和单元格结构，
只需重新计算系数并求解 signed-box 优化。


7. 特别注意事项
---------------

7.1 取消项

如果两个政策在同节点上映射到相同单元格，该项系数为 0。
这在 certificate 中被标记为 basis='CANCELLED'，不参与不确定性贡献。

7.2 E2 三分位暴露 + 对比

E2 的暴露值为 {0,1,2}。两个政策可能映射到不同的三分位等级。
需要检查：两个暴露等级是否都在 E2 的定义范围内（degree>0）。

7.3 D6 + 对比

D6 同样需要先检查 A5 profile exclusion assumption。
进一步，对比求解需要确认两个政策在 A5 检查后都在同一排除集合中。
否则返回 NEEDS_INPUT: DUAL_DESIGN_PROFILE_EXCLUSION_REQUIRED。


8. 结论
-------

Signed-box 优化方法为所有 30 种 D×E 组合提供统一的两政策对比框架。
它不需要分别为每种组合设计新的数学方法——只需在单元格枚举、支持概率
计算和目标系数构建上根据 D/E 参数化。

对比界的 sharp 性由锚点枚举和对偶乘子证明保证。
