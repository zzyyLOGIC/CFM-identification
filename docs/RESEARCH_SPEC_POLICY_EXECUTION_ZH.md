# 固定政策的内部属性与执行适配

更新日期：2026-11-24。对应[六项内部结构](IDENTIFICATION_STUDY_SPEC_ZH.md)。本次把固定政策均值、同一研究下的两政策均值差接入可构造数学输入的内部对象；没有更改 LLM 输出合同、数学求解、审核权限或估计协议。

## 从“看清旧记录”到“由属性构造输入”

前一阶段的 `InternalStudy` 是通用读取视图：按职责展开原记录，并能无损还原。它不能证明执行过程已经改用内部属性。

本阶段的 [PolicyQuestion](../cfm_id/research_spec_policy.py) 直接持有有类型的值，不保存旧 JSON，也不调用 `restore_legacy()`。原生输入由这些值构造：

```text
既有业务读取 / 已核对的材料
          ↓ 兼容适配：有明确值才转换
PolicyQuestion
  study       名单顺序、处理定义、结果定义及值域、共同背景
  evaluation  评价名单、按完整名单对齐的权重
  first       第一份完整二元安排
  second      第二份完整安排；单均值时没有第二端
  operation   均值 / 第一端减第二端
          ↓ 既有审核通过后，由内部属性构造
原生研究规格 + 原生目标
          ↓ 原有来源、科学条件、方法适用性检查
既有 POINT / PARTIAL 求解 → 独立证书重放 → 原有交接门槛
```

同一份两政策比较只有一份共同名单、结果、背景和评价权重，不让两个端点各自持有可独立改写的副本。原先分别保存的两端若不同，必须停止；不能选择其中一端覆盖另一端。相减方向由明确操作保留，不按大小排序。

## 属性与职责

| 对象 | 拥有的值 | 不能据此推出 |
|---|---|---|
| `StudyCoordinates` | 完整名单顺序、处理/结果定义、结果值域、共同 `context_reference` | 不能由名单推出评价人群；不能由处理定义推出历史分配设计 |
| `Evaluation` | 明确评价名单和完整长度的精确权重 | 不能把零权对象从完整政策向量删除，也不自动重新归一化 |
| `FixedPolicy` | 按名单顺序填写的完整 0/1 向量 | 固定政策不等于试点实际抽签；目标安排可能在原设计下没有正概率 |
| `PolicyQuestion` | 单端函数是均值、端点数、相减操作及共享坐标 | 不从 DTE、ATE 等名称补政策，不对两个单独区间直接相减 |
| 原有设计/暴露适配 | 历史分配参数、暴露映射参数 | 不产生科学许可；继续消费共享 D/E 登记 |
| 原有来源与科学审核 | 信息范围、采用态度、证据、精确审核绑定 | 不因内部对象完整就把“不采用”或“尚未决定”变成已采用 |

旧接口中时期与背景合在一个字符串里时，保留整段 `context_reference`；不能声称已分别结构化。二元编码来自既有合同，业务上的 0/1 含义仍由处理定义和原文审核负责。COUNT 在旧 POINT 接口中已有的连续值域嵌入保持不变，不因此开放计数结果的 sharp bounds。

## 维护位置与兼容要求

- [research_spec_coordinates.py](../cfm_id/research_spec_coordinates.py)：固定政策和局部效应共用的名单、定义、评价权重及原生研究构造；原导入路径保留兼容。
- [research_spec_policy.py](../cfm_id/research_spec_policy.py)：固定政策端点与操作约束。没有审核状态或自然语言推断。
- [research_spec_policy_adapters.py](../cfm_id/research_spec_policy_adapters.py)：旧读取/材料到属性，以及属性到原生构造器的边界。不得将未解释字段直接当作批准。
- [research_spec_catalog.py](../cfm_id/research_spec_catalog.py)：仍是六项维度和 D/E 模板定义的共同登记，不另建第二套分类表。
- [research_spec_model.py](../cfm_id/research_spec_model.py)：通用只读视图；不把可执行目标子集误标为所有六项都已经规范化。

属性构造前后原生输入和证书格式应保持相同，因此不重编号 D/E/R、不改证书版本。不覆盖原来源或原审核字段。属性与已审目标坐标不一致时拒绝执行；已修改原文、候选或科学条件仍需原有重新审核。

内部保留权重的原精确字符串；原生构造器按其既有行为约分，例如 `2/4` 变成 `1/2`。对照检查的是相同的原生输入及绑定，不要求取消既有数学规范化。
