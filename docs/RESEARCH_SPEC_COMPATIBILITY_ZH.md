# 六项属性对应与兼容验收

日期：2026-11-23；后续执行迁移更新于 2026-11-24。下文记录第一阶段的属性展开和无损兼容验收。固定政策、随机化局部比较及观察性网络目标的后续阶段已能独立构造原生输入，分别见[固定政策](RESEARCH_SPEC_POLICY_EXECUTION_ZH.md)、[局部效应](RESEARCH_SPEC_LOCAL_EXECUTION_ZH.md)和[观察性目标](RESEARCH_SPEC_OBSERVATIONAL_EXECUTION_ZH.md)。读取合同、页面布局、Prompt、Skill 和数学 Core 保持不变。

## 已实现的内容

| 内容 | 当前处理 |
|---|---|
| 旧字段归属 | 按明确格式及原路径归到六项；共同定义、来源、审核、结果和交接分开保留 |
| D/E 属性 | 已登记模板展开为分配单位、分配规则、阶段、筛选，以及参考对象、统计量、标签和边界；保留原编号与参数 |
| 目标 | 保留两端、方向、评价名单、权重、时期、背景与其余安排；不只凭 ATE、LATE 等名称补全定义 |
| 当前默认 PARTIAL | 区分模型原答、库的条件计算、材料条件、外层科学审核和交接权限 |
| 上传规格 | 登记当前 12 类原生操作与 6 条研究路线的显示适配；原上传版本和操作决定怎样展开 |
| 兼容检查 | 从分类字段和容器结构重建旧 JSON，再进入原解析、审核和执行路径比对 |

内部定义只维护在[共享登记](../cfm_id/research_spec_catalog.py)，由[内部研究模型](../cfm_id/research_spec_model.py)、实际读取字段校验和设计适配共同使用。[查看工具](../cfm_id/research_spec_view.py)消费内部模型；[旧格式适配](../cfm_id/research_spec_adapters.py)和[无损还原](../cfm_id/research_spec_projection.py)承担兼容。这些组织模块不调用读取器或求解器代替科学判断。

合并的是同一职责的重复登记：D3/D5 的分层名额字段和共同概率律描述、E1/E3 的严格过半规则，以及分散的业务模板—原生类型—构造入口映射。D3/D5 数学计算原本已共用条件超几何函数，本次没有重写它。R1a/R1b 等不同目标和前提不合并，旧证书类型也不改名。

内部模型用有含义的属性名，版本为 `internal-study-model/1`。原字段只存一份；属性保存来源引用及确定的模板定义。它区分“模板已确定”“保留原表达”“未知或待定”“未单独记录”。对任意旧自然语言的细分仍不声称已经自动解决。

例如，有限政策混合中的 `policy_probabilities` 属于目标政策；每个组成政策的 `study.assignment_design_json` 仍是历史分配机制。二者不能因都叫“概率”就合并。局部效应里的“其余安排按原设计条件平均”也不会被改成一份完整固定政策。

## 仍需核对的内容

- 背景字符串混写时期、场景和固定条件：原样保留并标出，不能自动拆成已采用条件。
- 旧布尔声明：不能据 `false` 判断是“不采用”，还是命题的否定。继续依赖原协议及原文。
- 未提及、未决定、冲突及显式不采用：保留各自状态，不填成已批准。
- 未知模板、版本、专用字段或缺参数：标出视图未展开；不推定该研究没有相应限制。
- 数学规格绑定到一条业务问题，不等于已证明规格忠实于问题；保留原审核。

“没有未归类字段”只说明字段有显示归属，不表示每个字段已拆成最细属性，更不表示来源语义正确、材料完备或研究可识别。

## 本轮实际验收

325 项针对性回归通过，覆盖内部分类、原视图、属性兼容、紧凑入口、首页能力、来源语义以及实际设计/暴露读取与效应分派；最后补充和调整内部分类后，相关的 158 项复测通过。两组有重叠，不相加计算总数，明细为本轮 `pytest.xml` 和 `pytest-final.xml`。未重复跑完整数学框架，也未调用项目 API。实际读取端的字段表、原生别名及生成的 JSON Schema 已与整理前逐项核对一致。

另外导出并逐项对照 33 份既有材料：

| 输入 | 对照结果 | 检查边界 |
|---|---|---|
| 7 份默认 PARTIAL 材料 | 7/7 的原区间、证书重放及原登记回执一致 | 未批准版本仍不得交接；批准使用原合成研究规则 |
| 26 份数学规格 | 26/26 重建前后完整执行返回一致 | 覆盖 12 类原生操作与 6 条研究路线；原审核要求和不支持状态保留，不新增自动估计权限 |

七网点仍为 `[3/7, 4/7]`；两政策差仍为 `[-1, 1]`；原文采用均值顺序的原题仍为 `[1/5, 1]`。DAG、IV、观察性网络、批量及加权目标也使用其原有规格进行对照。这里只报告转换保真，不将其解释为新的识别能力或 LLM 正确率。

针对性检查还覆盖：D1–D8 与 E1–E5 的八个固定配对、E1 平票/孤立点和 E2 阈值、D6 不采用/待定等阻断、目标或条件改变后旧审核失效。没有穷举所有 D×E 组合。

本地检查脚本、逐项结果与只读 HTML 放在开发目录 `reviews/capability-taxonomy-20261123/attribute-compatibility/`，不进入正式运行链路。
