# 一般图的多变量联合干预

2026-11-25，本地新增明确规格入口 `DAG_JOINT_ID`。旧单处理合同及其证书不变。

## 问题与依据

目标是 `P(Y | do(X=x))`，其中 X、Y 分别是非空、不交的变量集合。例如同时设定培训和补贴，研究收入分布。这里是一次联合干预，不能用两次单变量干预的结果拼接。

[Shpitser–Pearl（AAAI 2006）](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf)研究递归半马尔可夫因果模型中一个变量集合对另一个集合的干预分布，由完整观测联合分布构造 ID 表达式或不可识别见证。本次联网核对了原文摘要、问题定义与算法；项目复用已有集合递归，不新增图识别定理。

## 实现边界

| 项目 | 实际行为 |
|---|---|
| 输入 | `JointIdProblem`：显式 `treatments` 列表、结果集合、有向/双向边、模型、背景、总体信息与来源 |
| 图执行 | `dag_joint.solve` 把整个处理集合交给未改动的 `dag_id_solver._id` |
| 核验 | `dag_joint_verify` 检查集合根目标、每条图规则及子问题、重建表达式、来源摘要；另用联合干预数值模型交叉检查。数值检查不是识别定理的替代 |
| 不可识别 | 只有旧 hedge 检查器对原图、原干预集合实际通过，才报告 `NONIDENTIFIABLE`；其他停止保留其真实原因 |
| 科学确认 | 目标与角色、完整图和隐藏共同原因、递归模型与干预语义、总体分布和支持四项；确认绑定完整规格摘要 |
| 当前软件限制 | 有限离散变量，2–12 个观测节点，观测节点加双向边不超过 14；完整且严格正的总体联合分布。这些是入口/核验限制，不是所有图识别定理的必要条件 |
| 尚不支持 | 一般条件干预 `P(Y|do(X),Z)`、反事实、动态图、额外函数约束、自动数值估计交接 |

`context` 是研究背景说明，不会自动增加条件变量。有限样本不能代替完整总体信息声明；有额外约束时不能把它删除再按较大模型宣称不可识别。

## 调用与网页

`research_route_entry.run_registered_route('DAG_JOINT_ID', problem)` 先返回待确认记录。传入当前审核并明确选择研究协议，才执行。`dedicated_entries` 是 CLI、方法目录和网页共用的登记。

网页“数学库”可选择该入口，也可把 `causal-id.math-request/1` 规格随原问上传，按同一研究审核。结果显示识别公式、变量对应和原始证书。

默认“直答加核验”现已接入自然文字、变量边表和配套说明。模型原答保留；另一次来源读取明确处理集合、联合设定值、结果集合、时期、图及总体信息，由独立复核检查原文后，才生成上述规格。读取与复核都会载入 `cfm_id_llm/resources/joint_reading/SKILL.md`。

该文字入口仅接受无条件的联合干预分布，不能把条件干预、均值或两方案差悄悄改成分布问题。来源缺项会追问；额外限制不丢弃；科学前提仍需用户确认。每次确认绑定当前原文、读取和规格，修改输入后旧确认失效。新入口不自动向估计端发送查询。

真实模型与网页验收记录见开发目录 `reviews/joint-natural-20261125/README.md`；它与数学规格回归分别统计，不代表任意自然语言均能正确读取。
