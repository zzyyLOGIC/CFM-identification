## 已完成的范围

| 研究问题 | 已有能力与接入 | 仍需保留的边界 |
|---|---|---|
| 随机化网络局部效应 | 原设计条件平均；直接、同伴、局部总效应；已接目标合同内的权重、子群和多问题 | 任意 TaskSpec、线性组合和条件子群不能保证从任意自然文字自动读入；可使用明确规格 |
| 完整政策、签名政策及有限混合 | 默认入口已接原方法；保持政策权重、比较方向和逐对象支持；假设覆盖名单与完整安排范围分别审核 | 任意随机政策、连续处理和动态安排不在此合同内；签名支持不能替代均值充分性 |
| 观察性网络 | 完整/签名政策及有限组合；局部效应的观测律平均、共同分层和逐对象特征调整 | 不等于任意协变量调整、任意条件人群均已实现；不同平均方式不能混用条件 |
| 变量因果图 | 后门、指定调整集、前门、一般 ID；有限离散合同下的集合干预和联合结果；共同样本可请求符号总体函数 | 尚非条件干预、动态干预和一般反事实的通用入口；图外额外等式/不等式尚不能普遍联合核验 |
| 普通 ATE 与二元 IV | 随机 ATE、单臂 ATE 界、二元 Manski 界；二元 IV 的 LATE 和 ATE 界 | 不等于一般 ATT/CATE 业务入口全部完成；多值或连续工具与处理不属于二元 IV 合同 |
| 有限网络 PARTIAL | D1–D8 × E1–E5 的有限均值盒；同模型政策差与均值顺序；有限均值的线性等式/不等式联合求界 | 各原合同的设计、暴露和规模限制保留；不自动支持非线性、个体层限制和无限维模型 |
| 符号联合界限 | 固定有理系数、参数仿射右端与目标；输出端点公式、相容参数域及独立核验证书 | 参数进入约束矩阵或目标系数、任意非线性尚不支持；超出枚举上限报告资源停止 |

上述是已经实现并接入的范围，不是整个因果识别理论的完备性声明。方法名称和登记数量是软件维护信息，不是理论覆盖率。接口有字段也不等于对应数学能力已经完成。

## 接下来优先处理什么

1. **核对常见目标的剩余接入缺口。** 在已有模型内区分“数学已支持但自然入口未接”“读取合同缺项”和“确实需要新数学”；不要因新增名称而重复实现已有方法。
2. **保留全部已采用条件。** 已实现的有限线性约束进入共同模型求界；不能表达的图外或非线性条件明确停止。材料直接给出的目标数值只能作为来源核对，不能替代联合数学证明。
3. **按失败类型改进读取。** 使用固定自然业务和常规附件，区分接口错误、模型漏读、材料缺项和方法未覆盖。保留首次结果和有限恢复记录，不为通过率补条件或重复重抽答案。
4. **逐路线补齐下游交接。** 只交付与已审目标一致的总体查询或认证函数。原生公式、查询登记和样本估计是不同阶段；不能把回执当成估计已完成。

DiD、断点、多期处理和中介分析是后续可评估的常见方向，当前没有对应的专门完整路线；优先级应结合实际使用需求，不应先于现有网络目标的遗漏检查。

## POINT、PARTIAL 与未覆盖

对同一个已审核模型，考察全部相容的目标值：只有一个值时是 POINT；仍有范围时报告界限；没有相容模型是条件/信息冲突；算法或输入不支持则报告尚未覆盖。资源耗尽不能冒充不可识别。sharp 必须有针对完整模型的端点可达依据。

有限均值的联合约束现在已有数值和有限范围的符号实现，不能再沿用“只有独立均值盒”的旧描述。但这也不是一般离散因果模型的通用多项式求解器，更不是所有 PARTIAL 问题的完备算法。

## 条件与文献的维护要求

沿用[条件与验证目录](METHOD_CONDITIONS_AND_VERIFICATION_ZH.md)、[方法定义](METHOD_IDENTITIES_ZH.md)及 literature_support/routes，每种方法分别记录：目标与模型、定理条件、信息范围、研究者采用状态、程序检查、实现限制、结论与证书。文献背景、项目专门推导和已核验的定理对应应分开标明。

设计、暴露映射和目标分开维护；用暴露定义目标，不自动意味着暴露充分。一般图 ID 的集合干预能力已接入受支持合同，不能再写成只能单变量。联合线性界限的合同、推导及规模边界见[数值联合约束](FINITE_MEAN_LINEAR_CONSTRAINTS_ZH.md)与[符号联合界限](SYMBOLIC_JOINT_BOUNDS_ZH.md)。

## 网页的结果边界

页面围绕同一问题分别展示模型原答与数学库结果。模型答案保留；本机核验展示实际公式或界限、采用条件、证据状态和具体停止原因。两边都写 POINT 不等于目标与公式已经一致，来源核对也不等于公式验证。用户只回答必要追问和科学决定，不代替后台选择方法。

许可证、外部试用及发行反馈机制留待另行安排；当前工作重点仍是数学覆盖、读取交接和网页使用。
