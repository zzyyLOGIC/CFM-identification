# 方法名称、属性与兼容边界

当前开发以有明确含义的名称标识方法，不再以历史 R 编号组织现用方法计划。此项改变不增加数学能力，不改变公式，也不批准任何科学条件。

## 三个独立层次

| 层次 | 责任 | 维护位置 |
| --- | --- | --- |
| 基础方法 | 描述目标含义与识别依据，允许多个方法同时适用 | `cfm_id/method_definitions.py` |
| 目标操作 | 单均值、第一端减第二端、有限政策加权、干预分布等；操作须已实现 | 同文件的 `BindingShape`，对应各执行合同 |
| 具体实现 | 原生合同、生产及验证函数、设计／暴露支持范围与规模限制 | `policy_methods`、`local_methods`、`observational_methods`、`finite_policy_methods`、`dag_methods` 和原生合同 |

`method_catalog.catalog()` 同时返回基础方法 `definitions` 和现用执行绑定 `methods`。后者每项有 `definition_ids`、`operation`、`implementation`，并关联科学条件、总体信息、程序检查、实现限制、实际入口和证据核验方式。完整清单由 [方法条件目录](METHOD_CONDITIONS_AND_VERIFICATION_ZH.md) 自动生成。

例如 `network.randomized.full_policy_mean`、`network.randomized.full_policy_contrast` 和 `network.randomized.finite_policy_mean` 共享 `network.randomized.full_policy` 的基础方法，分别使用均值、差值和有限政策混合操作。它们仍使用各自原生合同与证书，不能仅凭同属一个基础方法就互换。

有限均值模型的设计特例归入实现属性；联合政策差在共同模型中直接求界。二元 IV 的 LATE 与 ATE 求界具有不同的目标和条件，共用一个响应类型实现不意味着两者的前提相同。单处理组 ATE 的有界和无有限界分支共享方法说明，但原生结果域与检查仍各自保留。

## 名称不能代替适用检查

这些维度是对现有实现的工程组织，不是文献规定的穷尽互斥分类，也不是程序必须依次经过的关卡。不解析名称前缀来判断能否执行。注册一个名称不会生成审核、扩大范围或启用回退。

匹配方法必须保留目标、信息、条件采用状态与来源。历史设计／暴露模板不自动生成所有交叉组合。新增业务通常只改变输入；新设计先核对既有方法所需的概率计算与科学前提；新假设可能需要新约束合同或新的识别依据。

理论区分的依据包括：

- [Aronow–Samii](https://arxiv.org/abs/1305.6156) 区分设计、暴露与研究目标；不规定本项目的方法编号。
- [Sävje](https://arxiv.org/abs/2103.06471) 区分暴露用于定义目标与用于限制干扰的假设。
- [Shpitser–Pearl](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf) 将图模型、观测信息和干预目标用于识别推导。
- [Duarte 等](https://arxiv.org/abs/2109.13471) 根据目标、信息及科学限制在相容模型中求界；不表示本项目已实现该文的全部能力。

两个均值分别识别可推出它们的差识别；反过来不成立。因此不能强制所有差值逐端识别，也不能把联合界限退化成独立区间相减。

## 历史记录如何处理

`cfm_id/method_compat.py` 是现用网络方法标识与原生历史标识的对应边界。仅用于查找与比较，不递归替换材料、证书或已签认的计划。

- 新共同业务计划、方法目录及显示名称使用可读标识。
- 原生数学模块、证书内容、证书哈希、原生条件查询和历史会话协议保持原格式，继续由原验证器处理。原生源码文件名暂不重命名。
- 原 Python 方法常量的导入兼容集中转交该模块，现用实现使用 `FULL_POLICY`、`SIGNATURE_POLICY` 等名称。
- 旧标识可查询相应方法描述或解析执行绑定，但不能获得审核权限。未知名称仍被关闭的登记拒绝。
- 已签认的旧计划不能通过字符串替换改成新计划。重新准备计划后，必须核对其当前审核绑定；不移植旧批准。历史原生证书的重放不需要改写。
- 新计划重新审核后，条件证据中的审核绑定随之更新，原生证书会对新证据重新计算哈希。对这类新旧运行应核对目标、条件、公式、界限及各自重放结果，不能要求证书哈希相同，更不能复制旧哈希冒充重新核验。对原样输入的历史原生规格，则仍可逐字核对旧结果。
- 网页可显示旧证据的友好名称，同时保留下载的原始证据。显示别名不参与科学判断。

## 本轮完成范围与后续工作

本轮整理方法名称、基础方法／操作／实现的对应关系，切换共同业务计划及其消费者，并保持原生证据边界。六项只读视图改为引用同一份方法定义，不另保留旧编号导航树。

本轮尚未把默认直答、简化入口及所有专用入口的候选准备逻辑合并为一个属性匹配器。现有专用判断继续保留。后续统一匹配时应消费这一份定义与原生条件，不能再建一套 R 编号分派，也不能把这里的描述文本当成可执行定理条件。

本轮验收关注新计划的名称、旧证书的原样核验、错误／缺项阻断以及网页和查询交接。它不等于重新测量真实 LLM 的阅读准确率。
