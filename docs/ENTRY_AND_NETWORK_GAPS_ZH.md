## 当前应如何理解“已接通”

数学求解、明确规格入口、默认自然语言读取、估计消费是不同层。下表不把“正确 JSON 可运行”当作“任意自然语言已读对”。联合干预及有限网络联合均值已增加真实 LLM 与首页上传测试，记录见开发目录 `reviews/joint-natural-20261125/README.md`。

本轮对 12 种原生网页操作、5 个既有研究适配及一般图入口共检查 34 份明确规格，额外覆盖 fixed/finite/observational/shared/nodewise 业务合同。它们不是所有参数组合的穷举。采用状态未定的负例仍停止。证书原内容不被诊断包装改写。

## 专用入口的共同诊断

`entry_diagnostics` 是只读展示层，不决定采用科学条件、不选一个更容易成功的方法、不改变结果。

- `method`：入口名称、为何使用该入口、显式选择还是已有分派记录；新集合目标/联合约束同时列出实际输入属性。
- `native_state`、`reason_code`：保留原方法状态和原因，包括资源停止。
- `missing_or_stopping`、`unconfirmed_declarations`：原方法追问及规格中实际尚未确认的声明。未确认声明不声称是唯一缺项。
- `candidate_findings`：只复制实际检查过的候选/尝试；未检查的其他方法不判为“不适用”。
- `result_evidence`：只汇总原执行记录的证据状态；本诊断不签发新证书。

原图、IV、旧 ATE/Manski、网络专用实现继续保留。新入口通过 `dedicated_entries` 统一登记，避免 CLI 和网页各写一份名字、合同和模块映射；没有为了统一返回值丢掉 hedge、资源限制或冲突证明。

本轮默认入口及诊断合同见 [网络默认入口](NETWORK_DEFAULT_ENTRY_ZH.md)。六种观察性资料算子有明确规格回归，真实网页测试按目标平均方式选取正负例，并非逐参数穷举；具体成功和失败均应查看验收报告。

## 下一步顺序

1. 集合干预：当前已交接处理集合、结果集合、时期及来源；扩展条件干预或均值/差值前需明确对应合同，不能把背景说明当条件变量。
2. 有限均值联合约束：当前已有完整坐标投影及独立重放；继续扩大模型范围前，先证明新增信息和限制能够完整表达，不能只增加一个字段。
3. 观察性合同已复用到默认入口；继续针对实际模型误读核对合同说明，不按个别业务另写识别分支。

这些工作不要求重新按业务题编号增加数学分支。新处理设计/暴露若能完整投影到已有模型，可共用求解；投影不成立或新增因果关系时，才是数学扩展。

## 新增接入的确切范围

- 完整政策与有限政策混合的均值差：保留第一端减第二端，逐份复用原数学方法和证书，再作固定有理线性组合。任一非零分量失败，整体不交付 POINT。
- 观察性均值差、有限混合、三种局部平均方式：真实研究可在显式科学确认后运行；来源、作用域、支持检查不变。
- 数值联合界限、符号联合界限、联合干预分布：可登记精确端点、参数查询或分布对象。登记不等于样本估计器已连接。
- 任意跨研究目标组合、处理后选择的子群、任意条件干预、连续处理和非线性约束，仍不能宣称已覆盖。已登记的专用规格入口保留；没有对应数学方法的情形不会靠更宽松读取合同放行。

接口、真实 LLM 与网页验收分别记录，不能用离线正确规格测试的通过率替代自然语言成功率。
