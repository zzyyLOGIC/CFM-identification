# 六项研究规格：再次评估与文献依据

文献核对日期：2026-11-23。本页保留整理依据，不作为另一套现行分类。当前结构和代码入口以[内部结构主说明](IDENTIFICATION_STUDY_SPEC_ZH.md)为准。结论：**六项用于组织研究规格，不称作统一的数学分类体系；内部按属性展开，允许关联和共存。** 没有迁移 LLM 合同或更改数学 Core。

## 再次评估后需要收紧的地方

| 项目 | 结论与调整 | 为什么 |
|---|---|---|
| 目标 | 保留；将单端函数与比较操作分开，再记录人群、权重、其余安排、时期和条件 | 均值是一端的汇总函数；相减是两端的操作。ATE/CATE/LATE 等也不只表达同一个属性 |
| 分配机制 | 保留；用分配单位、联合概率律、名额/分层、阶段和接受筛选来描述 | 整簇、分层和重随机化并不天然互斥。上一版“设计族”表只能当模板导航，不能当互斥树 |
| 暴露映射 | 保留；对现有 E 模板展开参考对象、统计量、标签和边界 | 这是当前映射的有用分解，不是对所有映射的限制；一般映射还可能依赖多跳信息、个体属性或输出向量 |
| 结构与模型 | 保留；对象关系网与变量因果图分开，明确模型适用域；结构性命题引用同一条假设记录 | 图本身常编码科学限制，结构与假设在数学上并不独立；不应让模型为两栏重复批准同一件事 |
| 已有信息 | 保留；补充资料如何产生：抽样、缺失、选择和测量方式 | 试验怎样分配处理与结果怎样被观察是两件事。若需要缺失机制假设，应在假设项单独审核 |
| 科学假设 | 保留；按作用导航，同时逐条保存命题、范围、采用态度与批准 | 按作用分组不是互斥分类；例如结构模型和一致性会共同约束观察与干预的联系 |

另外保留两个跨项属性：**来源**和**适用范围**。一个命题可以在多个栏目被引用，但只应有一份权威内容和审核记录。一个文档可以支持多项主张，但不意味着其中一句话支持所有参数。

“数学背景”由共同定义、模型适用域和科学条件共同表达。有限总体/超总体、固定/随机潜在结果、固定/随机网络、处理取值域和时间尺度应明确记录。缺少这些声明时保留原记录，不能为了让六栏齐全而默认采用某一种数学世界。

## 六项相互关联，并非独立开关

最重要的依赖是：

- **D 与 E 决定某种暴露有没有机会出现。** 不可仅看 E 的标签范围就批准正支持。
- **部分目标本身依赖 D。** 原设计内的局部效应按设计的条件分布平均；即使两端标签相同，换设计也可能改变目标。Sävje 的 Definition 1 后专门说明了这一点。
- **E 与科学假设分开，但有关联。** 同标签下潜在均值相等的假设必须指向明确映射、对象和安排范围；换 E 要重新核对这条假设。
- **模型限制与已有信息共同决定识别集合。** 不采用某条限制会扩大允许模型，而不是证明相反命题；有界模型中遗漏真正额外限制会改变所求问题。
- **评价总体与数据总体可能不同。** 视图分别呈现，不能因为都叫“总体”就自动对齐。

因此，本次不把规格写成“六个独立枚举值的笛卡尔积”，也不按六项机械增加定理组合。未来扩展仍检查目标、信息、条件与执行方法的实际匹配。
