# 观察性网络目标：平均方式、固定背景与执行边界

更新日期：2026-11-24。本阶段迁移观察性局部效应及固定政策均值的目标构造。没有改变数学 Core、科学条件、来源审核或 LLM 合同。[所有维护入口的状态](RESEARCH_SPEC_ENTRY_STATUS_ZH.md)另列，不把“已登记”“已迁移目标”“已支持自动读取”混为一谈。

## 三种局部目标不能互相替代

| 目标内部类型 | 什么保持固定 | 按什么平均 | 既有方法标识与必要科学条件 |
|---|---|---|---|
| `ObservedAllocationAverage` | 共同背景 W；每端的本人处理和同伴状态 | 该背景和局部状态下，实际采用规律中的其余安排 | `R3_P_STANDARDIZED_EFFECTS`；原完整处理向量条件交换性，不因暴露标签相同就要求潜在结果相同 |
| `SharedStratumAverage` | W；每端的本人处理和同伴状态 | 共同处理前分层 B 的总体分布 | `R3_EXPOSURE_ADJUSTED_EFFECTS`；原个体暴露充分性与给定 B、W 的暴露层条件均值交换性 |
| `NodewiseFeatureAverage` | W；每端的本人处理和同伴状态 | 各对象的局部特征 C_i 分布 | `R3_NODEWISE_EXPOSURE_ADJUSTED_EFFECTS`；原个体暴露充分性与给定 C_i、W 的局部条件均值交换性 |

这些路线还保留一致性、处理前固定网络和有限条件均值等原有前提。表中列出的是最易混淆的区别，不能替代原合同。

当前节点特征合同明确 `C_i=(本人二元 X, 全部图邻居中 X=1 的人数)`。即使处理暴露只参考核心伙伴，C_i 的邻居范围仍是完整关系图的全部邻居。这是现有方法的限定，不开放任意局部特征映射。

分层／节点调整目标不能只换一个标签就当作第一行的目标。它们所需的总体信息和科学条件也不同；有因子分解的观察分布并不表示曾经随机分配。

## 实际代码组织

- [research_spec_observational.py](../cfm_id/research_spec_observational.py) 保存 `FixedBackground`、三种平均方式、局部比较及观察性政策目标。
- [research_spec_observational_adapters.py](../cfm_id/research_spec_observational_adapters.py) 读取已确定的旧字段，构造旧目标坐标、原生研究和查询。平均方式与可接受总体算子的对应只登记一次，由入口检查和构造共同使用。
- [research_spec_coordinates.py](../cfm_id/research_spec_coordinates.py) 继续共用名单、定义、评价权重；`LocalState` 共用本人／同伴坐标；观察性目标不继承随机化的 `LocalQuestion`。
- [network_extended_dispatch.py](../cfm_id/network_extended_dispatch.py) 接入三条局部效应路线；[network_observational_policy_dispatch.py](../cfm_id/network_observational_policy_dispatch.py) 接入完整名单法与条件均值标签法。

```text
研究定义：名单、处理、结果、时期／业务背景
  + 固定处理前背景 W
  + 两端局部状态、评价名单和权重
  + 一种明确平均方式
        ↓ 与选定总体来源匹配
观察性目标对象
        ↓ 原来源、科学条件及版本绑定审核
原生研究与查询 + 原总体信息 + 原科学许可
        ↓ 既有求解与独立证书重放
原结果合同
```

共同分层变量 B 和节点特征 X 的定义从所选总体信息记录引用，不能总取信息列表第一条。其总体质量、条件处理概率、均值覆盖仍由原 A4 信息对象持有；不复制到目标中成为另一套可修改概率。

观察性固定政策使用 `ObservationalPolicyQuestion`：政策、评价与研究定义复用 `PolicyQuestion`，固定 W 单独保存。均值标签法额外需要的充分性及覆盖范围仍由原审核与许可负责。没有增加观察性两政策差或任意随机政策的自动入口，也没有开放原先拒绝的 COUNT 政策接口。

## 保留旧绑定，不猜测新条件

旧局部路线将原生背景编码为“业务背景 + fixed pretreatment W”；旧政策路线使用包含这两项的 JSON 字符串。内部现在分别保存两项，兼容适配仍输出原编码，使目标指纹、审核和证书保持一致。B、X 或 C_i 的分布不会被拼成固定 W。

局部比较仍为明确的第一端减第二端。经典观察性具名查询尚未连接反向本人状态的直接／总效应，仍按原规则停止；不能通过交换两端隐藏这个限制。独立证书重放、回传输入核对及估计权限均未改。

## 本地验收

`reviews/observational-model-migration-20261124/check_migration.py` 保存修改前适配器，对同一输入运行新旧路径。36 个场景完整返回一致，包含目标、审核绑定、原生输入、公式、结果及证书。其中包括三种平均方式、三种实际采用律表示、节点相关混合、子人群、局部总效应、五种标签及缺 W／不采用必要假设／额外限制／零支持等阻断。

单状态与有限随机政策两条原入口也纳入对照。另有 26 份原生／研究规格覆盖网页登记的 12 类原生操作和 6 条研究路线，审核与执行返回一致，保留原交接边界。

本次不调用 LLM，不操作真实浏览器；网页验收使用真实后端与既有参考输入。因此不声称自然语言读取率提升，也不声称观察性自由文本在默认首页的所有情形都已自动接通。
