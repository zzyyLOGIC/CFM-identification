# 旧原生 ATE：均值存在与完整模型检查

更新：2026-11-24。仅涉及保留的普通随机 ATE、单组 ATE 和二元 Manski 接口。网络 R1/R2/R3、网络 PARTIAL、DAG 和 IV 的数学公式与专用合同不变。

## 均值存在

普通 ATE 返回两条件总体均值之差；单组 ATE 使用已观察均值和缺失反事实均值的范围。这些表达式需要所用均值存在且有限。

- 二元结果、有限数值类别，或连续结果的两个有限上下界，可以提供均值存在的数学依据。
- 无界或仅有单侧界的连续结果，必须提供已审核采用的 `finite_conditional_first_moments`，且 evidence 非空。
- `PROPOSED`、`UNRESOLVED`、`NOT_ADMITTED` 不会被升级为采用。记录状态与 confirmed 不一致、存在冲突或明确矛盾时停止。
- 有界域推出均值存在不需要另造一条用户确认。结果的 `validity_domain.mean_existence_basis` 记录依据；使用明确矩条件时，`assumptions_used` 同时记录该条件。输入不会被改写。

上述要求用于本题涉及的潜在结果／总体条件均值。它不是从有限样本检验出均值存在，也不是把样本均值提升为总体均值。

## Manski 与单组 sharp 规则的完整模型

经典二元 Manski 规则只使用一致性、无干扰和观察总体 P(T,Y)，允许未观察的二元反事实自由补全。它不能在不处理更强限制的情况下仍对完整输入模型宣称最紧界。

当前准入规则：

| 输入情况 | 处理 |
| --- | --- |
| 基础模型，无额外限制 | 保持原公式、原 sharp 保证及原证书类型 |
| 二元结果另有已采用的有限均值声明 | 允许；这是二元域已蕴含的性质 |
| 额外条件已采用，或仍为提议／待定 | 停止，并指出条件名；不把它当作无效备注丢掉 |
| 额外提议明确标为 `NOT_ADMITTED` | 不加入模型，不因此阻断基础规则 |
| 条件记录矛盾或状态不一致 | 停止 |
| 二元域进一步排除 0 或 1 | 停止；原端点完成见证已不适用，不自行改算新界 |
| 额外图结构、不同总体信息、无法解释的 support 字段 | 停止，交给具备相应能力的合同 |

单组 ATE 的 sharp／全实线结论采用同样的完整性检查，允许基础随机设计条件及明确矩条件。当前单组规则只处理二元域或连续区间域；离散类别约束不被偷偷当成无限连续范围。

完整模型使用结构化字段表达：assumptions、variable_domains、information_signature、structure 和 support_domain。notes、description、provenance 是说明或来源文本，不能代替未编码的数学限制；读取／审核阶段仍须把真实限制保留到对应字段。

对这两个 sharp 规则，support_domain 仅接受既有 `assignment_probability`、`analysis_unit`；它们不授予其他科学许可。总体信息允许同一 P(T,Y) 的重复来源声明，但不接受另一实验制度、其他变量范围或专用强信息合同而忽略它们。更广支持范围应通过专用方法实现，不能放宽本规则来接入。

## 停止与重放

缺少均值依据：`LEGACY_ATE_FINITE_MEANS_REQUIRED`。

额外限制、额外信息、较窄二元域分别报告 `LEGACY_ATE_UNSUPPORTED_EXTRA_ASSUMPTION`、`LEGACY_ATE_UNSUPPORTED_EXTRA_INFORMATION`、`LEGACY_ATE_NARROWED_BINARY_DOMAIN` 等原因。旧接口仍使用 `UNSUPPORTED` 表示当前规则不适用；不改成“数学上不可识别”。

执行器先检查这些条件，验证器不调用执行器的检查函数，而从原始规格重新核对。故绕开生产检查、给旧证书增加新限制，或篡改均值依据，都不能获得 VERIFIED。

已有合法有限域证书可以继续重放；原本漏掉均值条件或忽略额外限制的旧证书会被拒绝。这是修正准入，不是修改公式或删除原始记录。

源码：`pfn_pipeline/_internal/identification/legacy_ate_contract.py`、`identification.py`、`verifier.py`。可机读说明：`pfn_pipeline.identification_assumption_inventory.legacy_ate_condition_catalog()`。验收：`tests/test_legacy_ate_conditions.py`。


## 默认网页的自然文字交接

普通 ATE 和二元 Manski 由 cfm_id/population_ate_entry.py 接到上述原生方法。基础公式来自原生方法；适配层仅对明确的反向目标转换已核验结果，不把模型原答当作证书。

流程为：保留原答 → 读取目标和条件 → 独立核对原文及字段职责 → 必要追问／科学条件确认 → 原生执行与独立重放。读取和核对使用同一份明确的字段合同，实现在 cfm_id_llm/population_ate_reading.py；核对不能只判断引文是否存在。读取错误最多自动重读一次，失败仍保留原答与原因，不要求用户为模型错误编写假设。

单个直答中的 `quantity=difference` 即使被模型放在答卷顶层，也仅可触发一次独立的原文读取；不修改原答，不将这些字段直接编译为数学规格。嵌套目标冲突、多目标、网络目标仍保持各自的审核入口。模型原答可能算错、比较方向写反，或遗漏可用界限；右侧库的独立结果不等于已经证明左侧原答正确。

读取合同中的 `conditional` 专指是否额外按特征条件或分层求效应，与是否采用科学前提无关。明确对完整目标人群求平均可读为 `false`；真正有歧义仍保留 `null` 并追问，不由程序默认补齐。请求中的来源编号枚举根据本次材料生成；`source_catalog` 是容器名，不是来源编号。无效来源或不在原文中的引句继续拒绝，自动重读反馈明确指出允许的编号；不会自动替模型修写证据。

复核请求另外提供独立的输出 Schema，列明本次待核对字段、来源编号和每项必须返回的六个字段；`question` 必须明确返回 `null` 或实际追问，不能省略。缺字段、额外字段、错误绑定、缺少条目或无效引文仍拒绝；缺字段反馈指出具体条目与字段名，不自动补成 MATCH。Schema 约束格式，不证明语义正确。格式合格后仍须执行原有来源、范围、条件状态和遗漏核对。

| 交接内容 | 规则 |
| --- | --- |
| 人群、时期、处理编码与方向 | 保留原文。支持完整人群的 1 减 0 或 0 减 1，且总体联合信息须适用于同一人群和时期。原生规格仍计算 1−0；0−1 明确记录为核验后取负，确认页及交付目标均显示实际方向；不交换原来的处理编码和分配概率，也不把条件子人群改成全体 |
| 原生 overall_population | 表示这份规格中联合分布的完整总体；原人群名称保存在 support_domain.analysis_unit，人群、时期、编码保存在查询说明及来源记录。不是将任意人群扩大为全体 |
| 结果取值 | numeric 表示数值结果，无需用户额外说明分布是否连续；转换为旧接口的实数域容器 continuous，不添加密度假设。保留原文界和离散限制，样本极值不是总体界 |
| 科学条件 | ADOPTED、NOT_ADOPTED、UNDECIDED 分别保留。待定内容不转换为未采用；额外已采用条件不能因旧方法不支持而删除 |
| 额外信息 | 仅包括实际额外总体对象、图结构或未表达的分配限制。“没有其他限制”和已经表达的随机安排不重复放入此字段；完整原材料仍由覆盖核对检查 |
| 科学确认 | 绑定当前材料、读取、核对和目标；模型核对不授予科学许可。修改后的目标、陈旧确认或不完整核对不能触发执行 |
| 公式、界限与证书 | 从既有原生方法取得，再由原验证器重放；反向结果另记录目标变换，direct_verification.replay 同时重建目标变换、适配报告与原生结果。证书不证明 LLM 对中文的解释必然正确，也不证明现实假设成立 |

当前网页交接只提供识别公式／界限；不自动下发估计查询。数值代入、条件分层、多目标、不同概率的复杂安排、额外图或总体对象仍保留原有专用入口，不宣称该小接口覆盖全库。公共调用 project.direct_then_verify 保持历史默认；网页显式启用 population_ate=True，其他调用者可以同样启用。

接口验收见 tests/test_population_ate_entry.py。真实 LLM 和浏览器运行记录单独保存在本地，不属于仓库产品文件；离线测试的模拟核对不计为真实模型理解成功。

## 反向目标的适配记录

`cfm_id/population_ate_orientation.py` 只接收已通过原验证器的普通 ATE 程序。对于 0−1，点公式交换相减两端，区间 `[L,U]` 转为 `[-U,-L]`；半无限区间同步交换端点及开闭性，全实线仍为全实线。这是同一目标取负的一一变换，不增加假设，也不增加新的识别定理。原生 1−0 结果和证书保留原样，不冒充成原生 0−1 证书。

`proof.target_operation` 记录原方向、请求方向、原生结果摘要、目标摘要及转换结果。未知程序类型不能套用此变换。前向历史报告不增加该字段；更改原文、目标、读取、审核、概率、公式或变换记录，完整报告重放即失败。缺少均值条件、额外限制尚不能处理等原有阻断继续生效。

验收见 `tests/test_population_ate_direction.py`：反向 POINT、Manski 和单组有界／半无限／无界结果；用二元缺失反事实的所有补全独立核对反向 Manski 端点；确认与证书篡改负例。网页分列模型原答和数学核验，不因两边都写 POINT 就宣称语义一致。
