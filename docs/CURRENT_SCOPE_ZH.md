# 当前能力与入口边界

更新于 2026-11-18。路径相对 Identification 包根；团队仓库嵌入在 `identification/`，个人仓库直接以此为根。

## 当前入口与配置

本机日常开发版的独立 ID 网页默认“一次读取与多方法匹配”，也可切换到完整分阶段流程。一次读取支持本地匹配原设计局部均值对比、完整名单政策均值、均值充分性下的标签方法、后门、一般图 ID 与二元 IV，匹配后的科学审核、原文绑定和证明核对仍须完成。观察性网络方法等使用完整分阶段流程。程序接口未指定读取模式时沿用分阶段行为。两条流程、旧编号的含义和估计交接详见[识别规格与方法](IDENTIFICATION_STUDY_SPEC_ZH.md)。

新应用使用 `cfm_id.project`，读取配置在 `cfm_id/configuration/reading.json`：A0 为 `target-first-skill-1`，网络事实为 `network-shared-definitions-1`，来源格式为 `short_refs`。实际模型 Skill 分别在 `cfm_id_llm/resources/causal_business_reading/` 和 `network_fact_reading/`。不要按协议编号大小自行切换配置。网页为观察性网络等家族显式选用已登记的专门读取配置；旧直接调用的默认值保留兼容。

原问题和材料 → 目标读取 → 意图与来源核对 → 专门事实读取 → A4 信息、A5 科学条件及目标绑定审核 → 定理应用／有限求界 → 独立证书重放。研究者提交目标和材料后，程序匹配候选方法；多问题逐问报告，不能用一问成功代表整题。

网页在后台执行读取复核，缺项或科学决定不明确时才追问。后台模型复核不能证明科学条件真实；明确拟采用的条件仍需独立科学确认。详见[框架合同](FRAMEWORK_CONTRACT_ZH.md)。

## 已接通的范围

当前共同登记有 **8 个事实家族、22 个方法计划**，团队和个人 ID 网页均承接此登记。方法数量不是业务成功率。运行事实以 `cfm_id.capability_registry.inventory()` 为准；完整方法名称见[能力登记](CAPABILITY_REGISTRY_ZH.md)。

| 目标 | 当前能力 | 关键边界 |
|---|---|---|
| 一份完整政策的均值 | 有支持的完整名单、均值充分性下的暴露标签、有限政策均值界 | 完整政策、评价范围、等权均值及信息明确。标签方法另审均值充分性 |
| 两份完整政策的第一端减第二端 | 两份名单或标签均值的有向差、有限联合差值界、均值顺序联合界 | 保留方向、共同人群／结果／背景；联合界不能用两个独立区间机械相减替代 |
| 随机化局部直接、同伴及局部总效应 | 原设计下的局部状态均值对比 | 直接与同伴效应研究接口已扩展到 D7/D8、加权及分组暴露。各目标须逐端检查支持，其余安排按原设计条件平均。[扩展范围](TASK1_LIMITATIONS_ZH.md) |
| 单个对象、单个局部状态均值 | 按原设计条件平均的单臂均值 | 明确本人和同伴状态；不扩展为任意多对象单臂聚合 |
| 有限份完整政策的加权均值 | 按政策权重组合有支持的完整名单均值 | 权重和全部政策明确，各分量分别检查支持并重放 |
| 观察性固定 W 下完整政策均值 | 固定背景内按完整名单或暴露标签识别 | 最多12对象；完整信息、条件交换性和支持；签名另审全安排均值充分性 |
| 观察性直接／同伴／局部总效应 | 按观察分配律平均、共同分层、本人与邻居二元特征调整 | 三种信息与交换性合同分别审核；不代表任意高维协变量调整 |
| 变量 DAG 干预分布 | 经典后门、调整、单变量经典前门 | 各自图、潜变量、总体分布及支持合同；不自动合并对象网络和变量 DAG |

历史合同索引见[规格与方法对照](IDENTIFICATION_STUDY_SPEC_ZH.md)。D1–D8 描述原分配律。E1–E5、固定权重暴露和分组暴露描述同伴状态。随机化局部效应在合成研究审核下可使用扩展设计和暴露。该适配器的外部研究审核仅接 D1/E1，另核对完整批次的信息。按暴露标签识别政策均值及有限均值盒各有自己的暴露范围。[设计和暴露入口](NETWORK_DESIGN_EXPOSURE_ENTRY_ZH.md) · [局部效应执行条件](../cfm_id/network_effect_dispatch.py)

有限均值盒 PARTIAL 已接 D1–D8/E1–E5 的单政策均值和两政策差值，限处理前固定简单无向网络、二元处理及完整均值模型：D1–D6 最多12节点，D7/D8 最多8节点。支持列明的精确总体数值或符号总体均值；符号结果给出经重放的上下界公式，不生成假定数值。数值 D2/E1 均值顺序仍走专门合同。科学界限、信息完整性及无额外联合约束仍需独立审核。sharp 仅相对于已审模型，不是估计置信区间。详见[有限均值模型](FINITE_MEAN_BOX_MATH_ZH.md)。

## 什么仍未解决

- LLM 首答及后台复核仍可能误读、漏引用或不符合 Schema；接口接通不等于自由文本稳定。
- 网络研究执行保留合成审核边界；真实审核者认证、多人撤销和生产准入尚未完成。
- 二元 IV 和一般图 ID 各有结构化研究接口，也已接入本机一次读取流程。完整分阶段登记的图路线包括后门、调整及经典单前门。一般图 ID 的现有子域为递归半马尔可夫离散模型、单个干预变量和完整观测总体联合律。扩展到网络与变量图联合模型、更广的 PARTIAL 仍需新合同。[一般图 ID 接入说明](DAG_ID_INTEGRATION_ZH.md)
- 库外建议是独立受控路径，标为 `LLM_UNVERIFIED`，不是网页失败后的自动兜底；没有任意新证明的万能验证器。
- 数学模块保留原物理位置以维持导入和证书兼容；扩展按[开发地图](DEVELOPMENT_ENTRY_ZH.md)区分业务适配与 Core。

## 停止原因与结论

| 情况 | 正确处理 |
|---|---|
| 格式、含义或引用错误 | 保留原答，定位后有界重读，重新审核；不能手改答案后算模型通过 |
| 原文缺项、未决定或冲突 | 追问；新材料使旧审核失效 |
| 拒绝审核、绑定或证书不匹配 | 阻断，不能放行数学结果 |
| 真正超出当前合同 | 报告未覆盖，不冒充不可识别证明 |
| 定理／求界执行且证书重放通过 | 报告 POINT/PARTIAL 等实际结论、公式与采用条件 |

“不采用”“尚未决定”和真实额外约束必须分开；有限记录不能升级为精确总体信息；暴露定义不推出暴露充分性。近期验收与遗留问题见[发布收尾记录](RELEASE_ACCEPTANCE_ZH.md)及[限制清单](KNOWN_LIMITATIONS_ZH.md)。历史小样本成绩保留在各专题验收文档，不汇总成当前整体准确率。


## 二元 IV 研究接口（2026-11-11）

二元 Z/D/Y 的 LATE 与 sharp ATE 界限可通过显式结构化接口使用。2026-11-18 的本机一次读取流程也可匹配该模型，条件表、工具、实际处理和相应科学决定均须审核。目标固定为 Y(1)-Y(0)。详见 [开发范围](IV_DEVELOPMENT_ZH.md) 与 [运行说明](IV_ACCEPTANCE_ZH.md)。

本机版对精确总体概率用有理数核对行和、相容性、原始与对偶可行性及两个端点是否相等。分数或十进制字符串能够保存输入精度，展示用的浮点数可能把两个端点显示得相同。概率表接口要求精确归一，样本估计与近似行和需要先有自己的数据合同。[已知限制](KNOWN_LIMITATIONS_ZH.md)
