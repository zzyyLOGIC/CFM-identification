# 当前能力与入口边界

更新于 2026-11-25。路径相对 Identification 包根；团队仓库嵌入在 `identification/`，个人仓库直接以此为根。本页说明随当前源码交付的能力；不声称对所有因果问题具有完备性。

## 当前入口与配置

本机日常开发版的独立 ID 网页默认“模型直答并核验，必要时自动继续完整审核”（`direct_verify`）。模型先提交答案草稿和结构化解释，程序按适用的既有数学方法复算、核对来源与条件；需要时进入后续读取和审核。另保留“一次读取与多方法匹配”和完整分阶段入口。默认入口不能验证任意模型证明；保留原答、材料核对通过、数学结果及证书核验通过是不同状态。程序接口未指定读取模式时仍按各自合同执行，不从网页默认值推断。研究字段与交接见[识别规格与方法](IDENTIFICATION_STUDY_SPEC_ZH.md)。

新应用使用 `cfm_id.project`，读取配置在 `cfm_id/configuration/reading.json`：A0 为 `target-first-skill-1`，网络事实为 `network-shared-definitions-1`，来源格式为 `short_refs`。实际模型 Skill 分别在 `cfm_id_llm/resources/causal_business_reading/` 和 `network_fact_reading/`。不要按协议编号大小自行切换配置。网页为观察性网络等家族显式选用已登记的专门读取配置；旧直接调用的默认值保留兼容。

分阶段路径为：原问题和材料 → 目标读取 → 意图与来源核对 → 专门事实读取 → A4 信息、A5 科学条件及目标绑定审核 → 定理应用／有限求界 → 证书核验。默认直答入口可调用其中所需环节，但不会由模型原答替代科学审核或数学执行。研究者提交目标和材料后，程序匹配候选方法；多问题逐问报告，不能用一问成功代表整题。各方法的核验方式不完全相同，见[条件与验证目录](METHOD_CONDITIONS_AND_VERIFICATION_ZH.md)。

网页在后台执行读取复核，缺项或科学决定不明确时才追问。后台模型复核不能证明科学条件真实；明确拟采用的条件仍需独立科学确认。详见[框架合同](FRAMEWORK_CONTRACT_ZH.md)。

默认结果页将 **LLM 原答** 与 **数学库核验** 分开显示。保留原答不等于认可原答，材料核对也不等于定理验证；没有数学结果时明确报告待核验或停止原因，不用模型自报的 POINT 代替核验结果。

## 已接通的范围

经典共同登记有 **8 个事实家族、22 个方法计划**；方法目录保留 **28 个执行标识**，另有联合干预、联合均值等专用合同。这些是入口和实现数量，不是完整理论分类、业务成功率或默认网页自由文本覆盖率。运行事实以 `cfm_id.capability_registry.inventory()`、`cfm_id.method_catalog.catalog()` 和专用入口登记为准；见[能力登记](CAPABILITY_REGISTRY_ZH.md)与[默认入口清单](DEFAULT_ENTRY_INVENTORY_ZH.md)。

## 已实现不等于理论上的全部覆盖

逐基础方法的条件依据、现存接口缺口及停用后端，见[数学覆盖核对](MATHEMATICAL_COVERAGE_AUDIT_ZH.md)。该核对区分文献充分定理、项目推导和指定模型内完备性，不是模型正确率报告。

- 随机化网络、观察性网络、变量图等是宽泛模型名称；不能用这些名称认定其下所有可点识别目标都已实现。必须同时限定目标、已有信息、科学条件和计算资源。
- 一般图 ID 的原文理论允许干预变量集合。旧 `DagIdProblem.treatment` 单变量合同保留，新联合干预适配器已复用同一递归算法；条件干预、动态方案或图与对象网络的任意组合未因此全部接通。原论文的完备性不等于当前全部接口的完备性。[Shpitser 与 Pearl (2006)](https://cdn.aaai.org/AAAI/2006/AAAI06-191.pdf)
- 有限均值盒的 sharp 保证来自其明确的可行模型和端点构造。联合均值入口另行处理完整模型中的等式和线性不等式，包括固定系数的仿射参数；这不表示个体潜在结果限制、平滑性、未知系数或非线性条件已经能统一投影。不能丢弃这些条件后宣称“全覆盖”。
- `CATE` 等目标名称出现在 Schema，不等于任意条件平均效应已接通；固定背景或分层路线已能回答其中一部分，仍需逐项核对目标、公式及入口。连续结果也不等于连续处理，二者不可混写支持范围。
- 当前优先工作是核对这些数学与入口缺口、条件依据以及 LLM 原答／库核验的展示；[本轮工作顺序](PUBLIC_RELEASE_PLAN_ZH.md)。许可证、分发、独立用户试用和发布机制暂不作为近期任务。

## 什么仍未解决

- LLM 首答及后台复核仍可能误读、漏引用或不符合 Schema；接口接通不等于自由文本稳定。
- 网络研究执行保留合成审核边界；真实审核者认证、多人撤销和生产准入尚未完成。
- 二元 IV 和一般图 ID 各有结构化研究接口，也已接入本机一次读取流程。完整分阶段登记的图路线包括后门、调整及经典单前门；默认联合干预使用单独版本合同，不改写旧单变量证书。当前一般图子域仍限递归半马尔可夫离散模型及原规模限制；缺变量、选择机制、一般条件干预和图上更广的 PARTIAL 未全部接入。[一般图 ID 接入说明](DAG_ID_INTEGRATION_ZH.md) · [联合干预样本合同](DAG_SAMPLE_SYMBOLIC_ID_ZH.md)
- 库外建议是独立受控路径，标为 `LLM_UNVERIFIED`，不是网页失败后的自动兜底；没有任意新证明的万能验证器。
- 数学模块保留原物理位置以维持导入和证书兼容；扩展按[开发地图](DEVELOPMENT_ENTRY_ZH.md)区分业务适配与 Core。

## 停止原因与结论

| 情况 | 正确处理 |
|---|---|
| 格式、含义或引用错误 | 保留原答，定位后有界重读，重新审核；不能手改答案后算模型通过 |
| 原文缺项、未决定或冲突 | 追问；新材料使旧审核失效 |
| 拒绝审核、绑定或证书不匹配 | 阻断，不能放行数学结果 |
| 真正超出当前合同 | 报告未覆盖，不冒充不可识别证明 |
| 定理／求界执行且证书重放通过 | 报告 POINT/PARTIAL 等实际结论、公式与采用条件 |

“不采用”“尚未决定”和真实额外约束必须分开；有限记录不能升级为精确总体信息；暴露定义不推出暴露充分性。近期验收与遗留问题见[发布收尾记录](RELEASE_ACCEPTANCE_ZH.md)及[限制清单](KNOWN_LIMITATIONS_ZH.md)。历史小样本成绩保留在各专题验收文档，不汇总成当前整体准确率。


## 二元 IV 研究接口（2026-11-11）

二元 Z/D/Y 的 LATE 与 sharp ATE 界限可通过显式结构化接口使用。2026-11-18 的本机一次读取流程也可匹配该模型，条件表、工具、实际处理和相应科学决定均须审核。目标固定为 Y(1)-Y(0)。详见 [开发范围](IV_DEVELOPMENT_ZH.md) 与 [运行说明](IV_ACCEPTANCE_ZH.md)。

本机版对精确总体概率用有理数核对行和、相容性、原始与对偶可行性及两个端点是否相等。分数或十进制字符串能够保存输入精度，展示用的浮点数可能把两个端点显示得相同。概率表接口要求精确归一，样本估计与近似行和需要先有自己的数据合同。[已知限制](KNOWN_LIMITATIONS_ZH.md)
