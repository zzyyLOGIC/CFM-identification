# 已有网络政策能力的原文读取

只恢复用户问题、资料和采用条件，不回答数学问题，不生成审批或证书。按给定 schema 输出完整 JSON。
每个事实及条件附给定的 source_id#L行号片段，可省略 quote；不引用模型原答，不自造来源。

- NETWORK_FINITE_POLICY：历史是随机试验，目标是一份固定完整名单，或按明确概率选择有限份完整名单；可问平均结果或两端差。固定政策只有一个component，probability=null、distribution_complete=null，无需另问它的选择概率。历史抽签 design 与未来混合概率不同。逐份保留所有对象的0/1安排，不换成每家独立抽签。
- NETWORK_OBSERVATIONAL_POLICY：历史安排不是随机试验，问完整固定政策或有限政策混合的平均结果或两端差值。每端是固定政策时只有一个component，probability=null；若为有限混合，逐项记录其选择概率。实际观察分配概率放 information.assignment_masses。不能从观察概率已知推出无混杂。
- 其他目标用 OTHER。多个独立问题、局部同伴事件不能改成政策水平；同一研究中的两个完整政策相减是一个DIFFERENCE目标，不是OTHER。

study.period 单列评价时期；fixed_background 只放目标固定的处理前背景，不把它改成需要平均的协变量。network 按完整名册和关系文件保留，未知留空，不推断遗漏边不存在。target.weights 明确保留评价权重；已明确所有对象等权可写精确的1/n，未评价对象只有明确不参与时才填0。不自动归一化。

information：总体资料用 SYMBOLIC_POPULATION_OPERATOR；样本用 FINITE_SAMPLE，符号总体公式不需要数值结果。
NODE_FULL_LAW表示每个结果与整个处理向量的总体联合律；FULL_JOINT_LAW表示全部结果与整个处理向量的联合律；ASSIGNMENT_NODE_MEANS只涵盖assignment_cells列出的完整安排。
NODE_SIGNATURE_MEANS表示本人和同伴状态格子的总体条件均值。signature_cells逐一保留资料实际覆盖的node、own、exposure，不能按目标补出没有提供的格子；其他算子留空。这个算子需要明确exposure定义和独立记录的mean_sufficiency许可才能外推完整政策，不能从分组统计自动批准充分性。完整总体律也可与均值充分性共同使用。均值无需填写数值，保留符号信息身份。
information.complete只问原文已给资料的覆盖清单是否完整保留；不要求所有理论格子有资料，不要求目标已能识别。给出了完整格子清单但只有部分状态有信息，可以complete=true；具体目标是否有信息由原数学库检查。范围核对字段mean_constraints按分派合同只指额外均值等式/顺序，不包含单独登记的mean_sufficiency；不能因此将它误报为NOT_STATED与采用充分性冲突。
观察性策略合同需要完整的实际安排概率表及每个正概率安排下各对象的总体条件均值算子，operator=OBSERVATIONAL_ASSIGNMENT_NODE_CONDITIONAL_MEANS。这些均值可为符号，不编数值。assignment_masses保留全部正概率行，亦登记这些行的条件均值覆盖；assignment_cells留空，不重复抄写同一名单。边际概率不擅自相乘。same_scope核对对象、结果、时期和固定背景，不表示目标安排有支持。

conditions逐项记录consistency、fixed_network、finite_means，以及实验的randomization或观察性的full_vector_exchangeability。均值签名充分性如原文采用，另记mean_sufficiency，实际范围单独保存在mean_sufficiency_scope，并引用原文：covered_nodes仅含明确采用的对象；scope按原文区分ALL_BINARY_ASSIGNMENTS（所有完整安排）、LISTED_ASSIGNMENTS（仅某些安排）或UNKNOWN。只对A采用而B、C、D不采用，covered_nodes只能为[A]，不得按目标名单扩展；仅试点安排成立不能升级为所有安排成立。LISTED_ASSIGNMENTS逐份保留assignments，其他范围留空。未知范围不补齐；这项假设尚未决定或不采用时可以scope=null，不根据分组表自动采用。二阶段设计另外记录first_stage_exclusion。未知条件保留UNKNOWN，不能自行批准。
randomization的科学含义是完整处理向量与所有潜在结果独立；仅给各对象独立抽签及其概率是design信息，不能单独当作这项科学许可的引文。原文另有明确采用声明时，statement和evidence应保留该声明；后续只补概率不应覆盖或替换原有科学声明。独立复核也须区分这两个含义，缺科学声明时保持UNKNOWN。
ADOPTED采用；NOT_ADOPTED不采用（不代表为假）；UNDECIDED尚未决定；UNKNOWN未说明；CONTRADICTED明确冲突。full_vector_exchangeability是固定背景下整个实际使用名单与各完整安排的潜在结果可比较，不等于只说明本人使用无混杂。
观察性材料明确不采用full_vector_exchangeability且结果定义为二元时，另记录complete_bounded_model：原文是否明确除了已列的条件总体均值、实际安排概率、结果定义和已采用条件之外没有其他限制。明确写“没有别的额外限制”可记ADOPTED；没有这类声明记UNKNOWN，不由字段空白推断。它是完整模型的声明，不是随机化或充分性，也不在remaining重复。完整模型仍可能包含其他限制，必须继续逐项保留，不能因此删除。
任何其他科学限制完整放remaining，不能遗漏或移到material_notes。没有其他限制不制造一条额外限制。material_notes可以保存数据说明及输出要求；与information一致重复不是误读。用户的后续回答可解决未知项，但不能无声覆盖明确矛盾。

完整安排政策使用整个处理向量；未采用均值充分性时，不需要另给暴露分组。单纯说“允许对象间相互影响”“不限制影响只看邻居人数”没有新增等式、独立性或排除限制，可作为STUDY_CONTEXT保留，不能制造interference_scope等ADOPTED限制；这也不表示影响必然存在。相反，“没有相互影响”“只受指定邻居影响”“同伴状态相同则均值相同”确实缩小模型，必须保留为科学条件，不能降为备注。
design等专用字段已经表达的缺项保留null/UNKNOWN，不在remaining重复为一项待采用的科学限制。历史抽签规则未知不表示目标固定政策还缺选择概率。只有原文另有无法表达的限制才放remaining；不知道一项当前方法用不到的可选定义，不自动产生额外限制。来源复核须检查这些区分，不能要求用户为模型错误补条件。

两份完整政策或有限政策混合的差：quantity=DIFFERENCE，components为第一端，reference_components为第二端，方向为第一端减第二端。每端混合概率分别合计1，不能把第二端写成负概率。均值没有第二端。观察性材料也可评价这些政策；政策选择概率不是历史采用概率，每份政策须使用原观察律单独核验支持。两端共同采用同一名单、权重、结果、时期和科学条件；不同研究不可合并。
