# 观察性网络局部问题

先保留用户比较的两种情况：本人的使用状态、同伴状态、评价对象、先减后减的方向、结果和时期。
再区分三种不同问题：在同一背景下按实际使用规律比较；先在共同的处理前分组中比较再平均；或按本人和邻居的处理前特征调整再平均。不要为了适配已有数据而改换平均方式。

使用概率是数据分布，不代表研究做过随机抽签。固定背景、要平均掉的分组、结果时期分别保留。
充分性、可比较性及其适用对象只能来自研究者明确采用的条件，不能由一张关系表或一种同伴状态定义推导。
一致性指实际结果对应实际执行的完整安排。结果充分性指不同完整安排只要本人及同伴状态相同，潜在结果就相同。两项各用其实际原文依据；确认充分性的追问回答不能替代原材料中一致性的引用。
没有说明或尚未决定的条件留空；不采用留 false。其余限制、冲突完整保留。
某项已有条件是否采用，只由对应 assumptions 字段表达；true、false、null 都一样，不能再将同一句复制为 additional_restrictions。只有另有一项当前字段表达不了的科学限制才放在那里；不能删除真实额外限制或原文矛盾。

读取与复核都应区分：未声明、不需要本方法使用，不等于研究者明确拒绝。仅有另一种条件的原句不能支持 false；没有采用态度的原文应为 null。复核理由若是“原文未声明”，不能把候选 false 判为 MATCH，必须要求重读；也不能反过来把明确不采用改成 null。

效应名称核对两端坐标：只有本人状态变为 DIRECT_EFFECT，只有同伴状态变为 SPILLOVER_EFFECT，两者都变为 LOCAL_TOTAL_EFFECT。名称与坐标矛盾时重新核对原问，不默认哪一项正确。已有完整人员配置表时，profiles.features 要按对象名单保留完整配置，不能只抄评价对象的特征。

按现有观察性字段合同交付，所有 source_ids 只用本次原文目录。表格的总体质量、单元覆盖和完整性均需原文支持。有限样本不改成总体信息；求符号公式不必编造结果数值。

同一总体使用规律及配套条件均值表共同组成一项 information，来源可来自不同附件，合并引用但不能丢失资料。covered_cells 表达均值表覆盖的坐标；表中均值符号不是 assignment_masses 的概率，也不必另列一项 OTHER。真正属于另一总体或额外关系的材料仍单独保留。

追问的回答只补充其明确涉及的内容。若用户仅确认某项前提，继续保留原两端、评价名单、时期和平均方式；若明确改问另一目标，则保留该修改，不能为了沿用旧结果而忽略它。此前读取只能帮助对照，不能成为原文或审批依据。
