# 联合目标与均值约束读取

先确定用户的一句话问题：是设定一个或多个变量，还是比较两份完整安排。单变量保留原单一目标，不能人为增加第二个干预。
变量因果图的节点是变量，对象关系网的节点是人、门店等对象；二者不能互换。
一个处理也可以对应多个结果的联合分布。保留完整结果集合，不拆题、不丢结果。单个处理的共同样本也可用于表达总体符号公式；仍须核对全部变量是否共同记录和本次采用的科学条件。

沿原文保留五件事：作用对象、处理/结果及时期、安排或图、已有信息、采用的限制。
时期独立放在 target.period，context 保留其他背景。读取汉语连续的时间、数字和量词时，先区分时间范围与对象/任务数量，不能将数量词改成日期。结果的单位也不能改变目标的时期。
关系表和数据说明都是来源，不是自动采用的科学假设。正文与附件冲突要保留并追问。
图变量的含义、0/1编码和离散值域保存在graph.variable_definitions。不要放进remaining变成额外限制。原文明确没有其他限制时，完整条件清单和空remaining足以表达；审核仍需检查原文有无遗漏，而不是要求重复抄写这句话。
解释为什么存在混杂、为什么直接比较两组不合适的定性背景，保留为STUDY_CONTEXT；已列出的因果关系仍完整写入图。不要从观察到的关联方向另造“本次采用”的潜在结果或干预均值限制。图边本身不包含效应符号；原文若独立声明采用均值顺序、逐人单调性、概率等式/不等式或效应符号，必须另行保留并审核，不可降为背景。判定依据是原文声明的作用，不是某个关键词。

遇到条件，先读清“采用/不采用/尚未决定”，再转写关系。不要为了证明模型答案而补前提。
有限样本平均值不是已知总体均值。每个结果有界和平均结果有界不是同一条件。
若明确声明本题所需平均结果存在且有限，用conditions.finite_first_moments保留原采用状态和引用；这是有限均值模型的有定义条件，不在remaining重复。未说明不补写，局部声明不扩范围，更强的分布或单调性限制仍另行完整保留。
DAG 样本仍按有限记录交接。另核对变量是否来自同一批共同测量的记录、是否对应本次研究人群；这些决定能否表达观测联合分布，不能靠变量名单猜测。符号识别公式不宣称总体数值已知，也不保证有限样本估计准确。
不只保留目标中出现的均值；额外等式或不等式涉及的对象也必须交接。
若材料直接给了某个干预概率，分别记录用户所问和材料给定的量及来源。核对干预值、事件、人群、时期、背景和条件，样本比例不能当精确总体概率。该记录只帮助展示材料已有数值，不代替数学证书，也不能删去图外限制。普通题不需要填写这部分。

按请求中给定的输出合同交付候选，并逐字标出来源。未知保留未知，数学推导和科学审批由后续处理。
